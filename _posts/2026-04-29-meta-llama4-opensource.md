## 한 줄 요약
> 추론 모델 경쟁이 클로즈드 API 진영에서 오픈소스로 옮겨붙었다. 메타가 그 불씨를 당겼다.

## 왜 지금 이게 중요한가?

지난 1년간 AI 추론 모델(reasoning model — 답을 바로 내놓는 대신 단계별로 생각 과정을 거쳐 복잡한 문제를 푸는 모델) 경쟁은 OpenAI의 o1·o3, 앤트로픽의 클로드 3.7 소넷, 구글의 제미나이 2.0 플래시 씽킹이 주도해왔다. 모두 클로즈드(closed) 모델이다. API 요금을 내야 쓸 수 있고, 가중치(weight — 모델 내부의 학습된 수치)를 공개하지 않는다.

메타가 2026년 4월 29일 라마 4(Llama 4) 시리즈를 오픈소스로 공개하면서 이 구도가 흔들리기 시작했다. AI타임스 보도에 따르면 라마 4는 추론 특화 버전을 포함한 세 가지 모델로 구성되며, 메타는 GPT-4o·클로드 3.5 소넷과 나란히 비교한 벤치마크 수치를 공개했다.

## 배경 — 기존에는 어땠나?

라마 시리즈는 메타가 2023년부터 오픈소스로 꾸준히 공개해온 대형 언어 모델이다. 라마 1·2·3 모두 연구·상업 이용 가능한 가중치를 무료로 내려받을 수 있어, 스타트업과 연구자들의 '기본 베이스 모델' 역할을 해왔다.

그러나 라마 3까지는 추론 능력에서 OpenAI o-시리즈에 비해 눈에 띄게 뒤처진다는 평가를 받았다. 수학 문제 풀기, 복잡한 코드 디버깅, 멀티스텝 논리 추론 같은 작업에서 격차가 컸다. 결국 '고성능 추론이 필요하면 API 진영의 클로즈드 모델을 써야 한다'는 시장의 암묵적 합의가 형성됐다.

라마 4는 이 합의를 깨려는 시도다.

## 핵심 — 무엇이 달라졌나?

라마 4 시리즈는 세 가지 모델로 구성된다.

- **Llama 4 Scout**: 경량화 버전. 코드 어시스턴트·챗봇 등 일상적 작업 최적화
- **Llama 4 Maverick**: 범용 성능 모델. GPT-4o 수준을 목표로 튜닝
- **Llama 4 Behemoth**: 추론 특화. o3·클로드 3.7 소넷과 같은 포지션

메타가 공개한 벤치마크에 따르면, Llama 4 Behemoth는 MATH-500(수학 문제 풀기 기준 벤치마크)에서 96.7점을 기록했다. GPT-4o가 같은 벤치마크에서 기록한 수치와 비슷한 수준이라고 메타 측은 밝혔다. 다만 이 수치는 메타 자체 발표 기준이며 외부 독립 검증은 아직 진행 중이다.

| 모델 | 포지션 | 가중치 공개 | 상업 이용 |
|-----|-------|----------|---------|
| Llama 4 Scout | 경량 범용 | 공개 | 가능 |
| Llama 4 Maverick | 범용 고성능 | 공개 | 가능 |
| Llama 4 Behemoth | 추론 특화 | 공개 | 가능 |
| OpenAI o3 | 추론 특화 | 비공개 | API 유료 |
| Claude 3.7 Sonnet | 추론 특화 | 비공개 | API 유료 |

오픈소스 추론 모델의 등장이 실질적으로 의미하는 바는 두 가지다. 첫째, 기업들이 추론 모델을 자체 서버에서 직접 호스팅할 수 있게 된다. API 비용이 제로다. 둘째, 의료·금융·법률처럼 데이터를 외부 서버로 보낼 수 없는 규제 산업에서 고성능 추론 모델을 처음으로 사용할 수 있게 된다.

## 시장 영향

라마 4 발표 직후 오픈소스 AI 인프라 기업들의 주가가 움직였다. 라마 모델을 클라우드에서 서빙하는 서비스를 제공하는 Groq, Together AI, Fireworks AI 같은 스타트업들에게 라마 4는 즉각적인 매출 기회다.

반대로 OpenAI와 앤트로픽의 API 요금 모델에는 하방 압력이 생긴다. 무료 오픈소스 모델이 충분히 강해지면 유료 API의 가격 정당성이 약해지기 때문이다. 2025년에 라마 3가 출시됐을 때도 GPT-3.5 API 요금이 대폭 인하됐다.

## 병규의 한 줄

라마 4에서 흥미로운 건 성능 수치보다 메타의 전략 선택이다. 추론 모델을 오픈소스로 내놓는 건 단순한 기술 공개가 아니라 '추론 능력은 차별화 포인트가 될 수 없다'는 선언이다. OpenAI가 추론으로 프리미엄을 붙이는 동안, 메타는 추론을 공유재로 만들어버리는 방식으로 싸운다.
