2025년 말 앤트로픽이 처음 공개한 '컴퓨터 사용(Computer Use)' 기능은 AI 에이전트가 실제 PC 화면을 보고 마우스와 키보드를 제어하는 시연으로 업계를 놀라게 했다. 그러나 실제 사용해본 개발자들의 반응은 엇갈렸다. 간단한 작업은 잘 됐지만, 5단계 이상의 복합 업무는 중간에 길을 잃거나 루프에 빠지기 일쑤였다.

그로부터 약 10개월이 지난 2026년 9월 30일, 앤트로픽이 '컴퓨터 사용 2.0'을 발표했다. 이번에는 달랐다.

## 무엇이 바뀌었나

컴퓨터 사용 2.0의 핵심 변화는 세 가지다.

**첫째, 작업 계획 능력이 달라졌다.** 기존 버전은 각 단계를 개별적으로 처리했다. 새 버전은 전체 작업을 먼저 분해하고, 중간에 오류가 생겨도 상위 목표를 유지하면서 경로를 재설정한다. 앤트로픽은 이를 '멀티-레벨 플래닝(Multi-level Planning)'이라 부른다. 마치 GPS가 도로 차단을 만나면 목적지는 유지한 채 경로만 재계산하는 것과 같은 방식이다.

**둘째, 오류 복구 루프가 생겼다.** 기존에는 예상치 못한 팝업이 뜨거나 로딩이 지연되면 에이전트가 멈추거나 엉뚱한 클릭을 반복했다. 이제 화면 상태를 실시간으로 재인식하고 스스로 다음 동작을 수정한다. 실제 업무 환경이 항상 깔끔하지 않다는 현실을 모델 수준에서 흡수한 것이다.

**셋째, 민감 정보 보호 레이어가 추가됐다.** 에이전트가 비밀번호 입력창이나 신용카드 폼을 감지하면 자동으로 사람에게 제어권을 넘긴다. AI 에이전트 보안 사고가 잇따르는 상황에서 앤트로픽이 선제적으로 설계에 박아 넣은 장치다.

## 성능 수치

앤트로픽이 공개한 내부 벤치마크에서 컴퓨터 사용 2.0은 OSWorld(실제 PC 화면 제어 능력을 평가하는 에이전트 벤치마크)에서 72.3%를 기록했다. 기존 1.0 버전의 43.1%에서 크게 올랐다. 인간 전문가 수준(약 85%)에는 아직 미치지 못하지만, 업계에서는 '실무 투입 가능 임계점'으로 평가한다.

| 항목 | 컴퓨터 사용 1.0 | 컴퓨터 사용 2.0 |
|------|----------------|----------------|
| OSWorld 성공률 | 43.1% | 72.3% |
| 최대 연속 작업 단계 | 8단계 | 22단계 |
| 오류 후 자동 복구 | 없음 | 있음 |
| 민감 정보 처리 | 직접 입력 | 사람에게 위임 |

## 국내 반응

국내 AI 업무 자동화 스타트업들의 관심이 빠르게 쏠리고 있다. 반복적인 ERP(전사적 자원 관리 시스템) 데이터 입력, 레거시 소프트웨어 연동, 이메일 처리 흐름 등 API가 없는 시스템을 제어해야 하는 업무에서 컴퓨터 사용 기능의 수요가 크다. API 접근 대기자 명단이 공개 하루 만에 마감됐다.

이번 업데이트에서 흥미로운 건 수치보다 설계 철학이다. 앤트로픽은 에이전트가 '모든 걸 혼자 완결하는 것'을 목표로 삼지 않았다. 민감한 순간에는 사람에게 돌아오는 구조 — AI와 사람이 업무를 분담하는 방식을 처음부터 제품 설계에 새긴 것이다. 자율성과 안전성을 동시에 잡으려는 접근이 경쟁사와 다른 앤트로픽의 차별점으로 자리잡고 있다.
