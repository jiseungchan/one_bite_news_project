## 리드

알리바바 클라우드가 2026년 5월 공개한 Qwen3 시리즈가 AI 커뮤니티에서 빠르게 주목받고 있다. 최상위 모델 Qwen3-235B-A22B는 Hugging Face(오픈소스 AI 모델 공유 플랫폼) 다운로드 수 기준으로 공개 1주일 만에 100만 건을 돌파했다. 비용 효율을 중시하는 중간 크기 모델 Qwen3-30B-A3B는 클라우드 API 단가를 기준으로 GPT-4.1 mini 대비 60% 저렴하면서도 수학 벤치마크 MATH-500에서 동등한 성능을 보였다.

## 배경 — 기존에는 어땠나?

중국 AI 모델이 본격적으로 글로벌 오픈소스 시장에서 두각을 나타낸 건 2025년 초 DeepSeek-R1이 계기였다. 당시 미국 AI 업계는 충격을 받았다. 훨씬 적은 훈련 비용으로 o1에 근접한 추론 성능을 보인 DeepSeek는 "미국이 AI 패권을 독점하고 있다"는 통념을 흔들었다.

그 이후 중국 AI 기업들의 오픈소스 전략이 달라졌다. 단순히 성능을 높이는 데서 벗어나, '상업적 사용 허가'와 '다양한 크기 제공'이라는 실용적 조건을 내걸기 시작했다. 기업이 자체 서버에 올려 쓸 수 있도록 하는 것이다.

Qwen 시리즈도 이 흐름의 연장선이다. Qwen2가 2024년 공개됐고, 이번 Qwen3는 MoE(Mixture of Experts — 모델이 입력에 따라 활성화하는 파라미터 집합을 동적으로 선택하는 구조)를 전면 채택해 실제 연산에 사용되는 파라미터 수를 줄이면서 전체 모델 크기는 유지했다.

## 핵심 — 무엇이 다른가?

Qwen3의 핵심 변화는 두 가지다.

첫째, 'Thinking 모드'와 'Non-thinking 모드'를 사용자가 직접 전환할 수 있다. 추론이 필요한 복잡한 수학 문제에는 천천히 단계별 사고 과정을 거치고, 간단한 질문에는 빠르게 답을 뱉도록 모드를 바꿀 수 있다. 이 선택권은 기존 추론 모델들이 항상 느리게 작동하던 단점을 보완한다.

둘째, 119개 언어를 지원한다. 기존 서방 오픈소스 모델들이 영어 중심이었던 것과 달리, 아랍어·힌디어·한국어 등 비영어권 언어 처리 성능을 의도적으로 끌어올렸다. 이는 동남아·중동 시장을 겨냥한 전략적 선택으로 읽힌다.

| 항목 | Qwen3-235B | GPT-4.1 | Claude Sonnet 4 |
|------|-----------|---------|----------------|
| 라이선스 | Apache 2.0 (상업 무료) | 유료 API 전용 | 유료 API 전용 |
| MATH-500 | 97.2% | 95.1% | 94.3% |
| HumanEval (코딩) | 92.8% | 91.4% | 90.2% |
| 지원 언어 수 | 119개 | 주요 20개 | 주요 30개 |

## 시장 영향 — 어디에 쓰이나?

- 비용 민감 스타트업: Apache 2.0 라이선스(상업적 사용 무료 허가) 덕분에 API 비용 없이 자체 서버 배포 가능
- 국내 영향: 한국어 지원 모델 중 무료 오픈소스로 상위권에 처음 진입한 중국 모델. 국내 AI 스타트업의 기반 모델 선택지가 늘었다
- 엔비디아 GPU 수요: MoE 구조 모델의 확산은 추론 단계 GPU 메모리 요구량을 낮추는 방향으로 작용해, 고가 H100보다 중간급 GPU 수요를 높인다는 분석이 나온다

## 병규의 한 줄

> Qwen3가 흥미로운 건 성능 수치보다 'Apache 2.0 라이선스'라는 한 줄이다. 상업 무료로 235B 모델을 쓸 수 있다는 건, 미국 빅테크 모델 API에 의존하는 구조 자체를 흔드는 가격 압박이다. 중국 AI 기업이 오픈소스를 전략 무기로 쓰고 있다는 게 점점 분명해진다.
