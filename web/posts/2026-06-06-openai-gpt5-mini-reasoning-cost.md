## 한 줄 요약
> 강력한 추론 AI가 드디어 일반 소비자 가격대에 도달했다 — 추론 모델의 민주화가 시작됐다.

## 리드 — 왜 지금 이게 중요한가?

OpenAI가 GPT-5 Mini를 공개했다. 핵심은 가격이다. GPT-5 API 기준 입력 토큰 1백만 개당 15달러였던 것이 Mini에서는 3달러로 내려왔다. 80% 인하다. 그러면서도 수학·코딩·과학 추론 벤치마크에서 GPT-5의 90% 수준 성능을 유지했다고 OpenAI는 밝혔다. ChatGPT Plus(월 20달러) 구독자에게도 GPT-5 Mini 접근권이 포함됐다.

## 배경 — 기존에는 어땠나?

추론 모델(Reasoning Model)은 답을 바로 내놓지 않고, 문제를 단계적으로 분해해가며 '생각하는 과정'을 거치는 AI다. OpenAI의 o1, o3, 그리고 GPT-5가 이 방식을 사용한다. 일반적인 언어 모델보다 훨씬 높은 정확도를 보이지만, 그 대신 연산 비용이 크게 올라간다는 트레이드오프(두 가지를 동시에 최적화하기 어려운 상충 관계)가 있었다.

실제로 GPT-5 API 비용은 GPT-4o 대비 5~7배 수준이어서, 스타트업이나 개인 개발자가 추론 기능을 서비스에 통합하기에는 부담이 컸다. "성능은 좋지만 비싸서 쓰지 못하는" 기술이 반복됐다. Claude 3.5 Opus, Gemini 2.0 Ultra도 같은 패턴이었다. 최고 성능 모델이 나오고, 몇 달 뒤에 경량 버전이 나오는 사이클이 이제 업계 표준이 됐다.

추론 모델의 비용이 높은 이유는 '사고 연쇄(Chain-of-Thought)'를 처리하는 데 훨씬 많은 토큰이 소모되기 때문이다. 단순 질문에도 내부적으로 수백~수천 단계의 추론 과정을 거치다 보니 비용이 선형적이 아닌 기하급수적으로 올라갔다.

## 핵심 — 무엇이 다른가?

GPT-5 Mini가 비용을 낮출 수 있었던 핵심 기술은 '선택적 추론(Selective Reasoning)'이다. 모든 질문에 동일한 추론 깊이를 적용하는 것이 아니라, 쉬운 질문에는 빠른 응답을, 복잡한 질문에만 깊은 추론을 자동으로 배분한다. 마치 사람이 간단한 덧셈은 암산으로, 복잡한 방정식은 종이에 써가며 푸는 것처럼 작동한다.

| 항목 | GPT-5 | GPT-5 Mini |
|------|-------|------------|
| API 비용 (입력/100만 토큰) | $15 | $3 |
| 수학 추론 벤치마크 | 기준 | -8%p |
| 코딩 벤치마크 | 기준 | -6%p |
| 응답 속도 | 느림 | 2.3배 빠름 |
| ChatGPT Plus 포함 | 포함 | 포함 |

성능 하락폭(6~8%p)보다 비용 절감 폭(80%)이 훨씬 크다. 대부분의 실용 시나리오에서 Mini가 더 합리적인 선택이 되는 구간이 생겼다.

## 시장 영향 — 어디에 쓰이나?

- **개인 개발자·스타트업**: API 비용 부담 없이 추론 기능을 서비스에 통합 가능. 코딩 어시스턴트, 법률 문서 검토 앱, 교육 플랫폼 등의 수요 증가 예상
- **기업 자동화**: 비용 민감 대량 처리 워크로드(배치 분석, 고객 문의 분류 등)에 추론 AI 적용 가능해짐
- **경쟁 구도**: Anthropic의 Claude Haiku 4, Google의 Gemini Flash 2.5와 직접 경쟁. 경량 추론 모델 시장이 본격 형성됨

## 병규의 한 줄

추론 AI의 비용이 낮아지는 것은 단순한 가격 경쟁이 아니다. "AI가 생각하는 능력"이 프리미엄 기능에서 기본 기능으로 내려오는 순간이다 — 그 다음에 무엇이 프리미엄이 될지가 더 궁금하다.
