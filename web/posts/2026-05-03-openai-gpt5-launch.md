## OpenAI가 모델 난립을 끝내다

지금까지 OpenAI를 써본 사람이라면 한 번쯤 혼란을 겪었을 것이다. GPT-4o, GPT-4o mini, o1, o1-mini, o3, o3-mini, GPT-4.1… 무엇을 언제 쓰면 되는지, 솔직히 알기 어렵다. OpenAI 내부에서도 이 복잡성이 문제였던 것 같다.

2026년 5월 2일(현지시각), OpenAI는 GPT-5를 공개하면서 이 혼란에 마침표를 찍겠다고 선언했다. 핵심 메시지는 단순하다. "이제 GPT-5 하나만 쓰면 된다."

## 기존에는 왜 이렇게 복잡했나

GPT-4 계열이 등장한 이후 OpenAI는 서로 다른 목적으로 설계된 모델을 각각 출시해 왔다. GPT-4o는 빠른 멀티모달 처리에 강점이 있었고, o1·o3 시리즈는 수학·코딩처럼 단계적 추론이 필요한 작업에 특화됐다. 문제는 이 두 계열이 아키텍처(설계 구조)부터 달랐다는 점이다.

사용자 입장에서는 "지금 내 질문이 추론형인지 생성형인지"를 스스로 판단해 모델을 선택해야 했다. 이건 일반 사용자에게는 너무 높은 진입 장벽이다.

GPT-5는 이 두 계열을 하나로 합쳤다. 기술적으로는 **멀티모달 기반 위에 추론 체인(chain-of-thought, 문제를 단계별로 쪼개서 생각하는 방식)을 내재화**한 단일 모델이다.

## GPT-5가 GPT-4o, o3와 다른 점

| 항목 | GPT-4o | o3 | GPT-5 |
|------|--------|-----|-------|
| 텍스트 생성 | 우수 | 보통 | 우수 |
| 수학·추론 | 보통 | 우수 | 우수 |
| 이미지 입력 | 가능 | 제한적 | 가능 (향상) |
| 음성 대화 | 가능 | 불가 | 가능 |
| 응답 속도 | 빠름 | 느림 | 빠름 (o3 수준 추론 유지) |
| 컨텍스트 창 | 128K 토큰 | 200K 토큰 | 256K 토큰 |

컨텍스트 창(context window, 한 번의 대화에서 모델이 기억할 수 있는 텍스트 분량)이 256K 토큰으로 늘었다. 책 한 권 분량을 통째로 집어넣고 질문할 수 있는 수준이다.

OpenAI가 공개한 벤치마크(성능 측정 지표) 수치를 보면:

- **MMLU(광범위한 지식 측정 시험)**: o3 대비 4.2%p 향상, 92.1% 달성
- **HumanEval(코딩 능력 테스트)**: 89.3% → 94.7%로 상승
- **GPQA Diamond(대학원 수준 과학 문제)**: 69.1% → 75.8%
- **실시간 음성 대화 지연**: 평균 230ms → 140ms로 단축

## 무엇이 바뀌고, 어디에 영향을 주나

GPT-5의 실질적 변화는 크게 두 가지다.

**첫째, 비용 구조.** ChatGPT Plus(월 20달러) 구독자는 GPT-5를 기본 모델로 사용하게 된다. 기존 GPT-4o와 같은 가격에 o3급 추론 능력을 쓸 수 있다는 의미다. API 가격은 입력 1M 토큰 기준 15달러로, GPT-4o(10달러)보다 비싸지만 o3(60달러)보다 훨씬 저렴하다.

**둘째, 에이전트(agent, 스스로 작업을 계획하고 실행하는 AI 시스템) 활용.** 긴 컨텍스트와 향상된 추론 능력은 AI 에이전트가 복잡한 멀티스텝 작업을 처리하는 데 직접적으로 유리하다. 코딩 에이전트, 리서치 에이전트, 업무 자동화 영역에서 활용 폭이 넓어질 전망이다.

국내 기업 입장에서는 API 단가가 o3 대비 4분의 1 수준으로 내려갔다는 점이 중요하다. 고비용을 이유로 o3 도입을 주저하던 기업들의 도입 장벽이 낮아진다.

## 병규의 한 줄

이번에 흥미로운 건 성능 수치보다 '통합'이라는 결정이다. 더 빠르거나 더 정확한 모델을 내놓는 건 예견된 수순이었다. OpenAI가 선택한 건 "선택지를 없애는 것" — 복잡성 자체를 경쟁 우위로 삼았던 전략을 스스로 포기한 것이다. 사용자 경험을 단순화하는 게 장기 시장 지배력에 더 유리하다고 판단한 셈인데, 이건 제품 전략의 전환점이기도 하다.
