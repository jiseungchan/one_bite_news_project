## 리드

SK텔레콤이 2026년 5월 기존 AI 개인 비서 서비스 '에이닷'을 에이전트(agent — 사용자의 지시 없이도 스스로 판단하고 행동하는 AI) 기반으로 전면 개편했다. 통화 내용을 요약해주는 기능으로 출발한 에이닷이 이제 사용자의 일정을 읽고, 배달 음식을 주문하고, 카드사 앱과 연동해 결제까지 처리한다.

## 배경 — 기존에는 어땠나?

에이닷은 2022년 출시 당시 '통화 녹음 후 AI 요약'이라는 단일 기능으로 주목받았다. 회의 전화 후 자동으로 핵심 내용을 문자로 정리해주는 기능은 특히 B2B(기업 간 거래) 영업직군에서 호평을 받았다. 이후 실시간 통역·보이스피싱 감지 기능이 추가됐지만, 본질적으로는 '사후 정리 도구'에 가까웠다.

업계 전반에서 AI 서비스의 한계로 지적됐던 것도 같은 문제였다. 정보를 요약하거나 설명하는 데는 능숙하지만, "그래서 뭔가를 직접 해주는" 단계까지는 넘어가지 못했다. 사용자가 요약된 회의록을 받아도, 후속 일정 잡기는 여전히 사람이 직접 캘린더를 열어야 했다.

## 핵심 — 무엇이 달라졌나?

이번 개편의 핵심은 '도구 사용 권한'의 확장이다. 새로운 에이닷 에이전트는 사용자의 스마트폰 앱 15종과 API(응용 프로그램 인터페이스 — 서로 다른 소프트웨어가 대화하는 통로)를 통해 직접 연결된다.

동작 방식을 단계로 보면 이렇다.

1. 사용자가 통화를 마치면 에이닷이 대화를 분석한다.
2. "내일 오전 10시에 자료 보내달라"는 약속이 감지되면, 자동으로 캘린더에 알림을 등록한다.
3. "저녁 같이 하자"는 대화가 잡히면 인근 식당 예약 앱과 연동해 후보를 추천하고 예약 여부를 묻는다.
4. 사용자가 승인하면 에이닷이 직접 예약을 완료한다.

| 항목 | 기존 에이닷 | 개편 에이닷 에이전트 |
|------|----------|------------------|
| 동작 방식 | 통화 후 요약 제공 | 통화 내용 기반 자동 실행 |
| 연동 서비스 | 없음 | 15개 앱 (캘린더·배달·금융 등) |
| 사용자 개입 | 요약 읽고 직접 처리 | 승인 한 번으로 완료 |
| AI 모델 | 자체 경량 모델 | 에이닷 LM + 오케스트레이션 레이어 |

SKT에 따르면 베타 테스트 기간 중 에이전트 기능 사용자 중 67%가 일정 자동 등록 기능을 매일 사용했고, 월간 활성 사용자(MAU) 기준 전월 대비 38% 증가했다.

## 시장 영향 — 어디에 쓰이나?

- 통신사 AI 경쟁: KT는 '지니(Genie)' 에이전트를 3분기 출시 예정, LG유플러스는 '익시(ixi)' 기반 에이전트 기능을 연내 적용 계획이다. 국내 통신 3사가 AI 에이전트로 동시에 전환하는 구도다.
- B2B 확장: 기업용 버전 '에이닷 비즈'는 CRM(고객 관계 관리 시스템)과 연동해 영업 담당자의 통화 후속 처리를 자동화한다. 현대캐피탈이 파일럿을 진행 중이다.
- 개인정보 이슈: 통화 내용과 앱 사용 데이터를 AI가 실시간으로 읽는 구조인 만큼, 개인정보보호위원회가 데이터 처리 방식 검토에 들어갔다고 알려졌다.

## 병규의 한 줄

> 에이닷 개편이 흥미로운 건 '뭘 할 수 있냐'보다 '어디까지 허용하느냐'의 문제로 이동하고 있다는 점이다. AI 에이전트 시대의 핵심 질문은 기술 성능이 아니라 신뢰 — 내 통화 내용과 일정을 AI가 들여다보는 걸 얼마나 편하게 받아들이느냐가 확산 속도를 결정한다.
