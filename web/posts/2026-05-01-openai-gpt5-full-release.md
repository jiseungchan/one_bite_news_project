## 기존에는 어땠나

지금까지 OpenAI의 모델 라인업은 목적별로 분산돼 있었다. GPT-4o는 멀티모달(텍스트·이미지·음성을 동시에 처리하는 방식) 대화에 특화됐고, o3·o4-mini 계열은 수학·코딩 같은 단계적 추론에 특화됐다. 개발자들은 작업 유형에 따라 모델을 골라야 했다. 빠른 답변이 필요하면 GPT-4o, 복잡한 논리 추론이 필요하면 o4-mini 식으로.

이 분산 구조는 편의성보다 복잡성을 만들었다. API 호출 비용을 최적화하려면 두 모델을 오가며 라우팅 로직을 직접 짜야 했다. 일반 사용자 입장에서는 "어느 모델을 써야 하나"라는 질문 자체가 장벽이었다.

## 무엇이 다른가

GPT-5는 이 구조를 통합한다. 단일 모델이 상황에 따라 빠른 응답 모드와 깊은 추론 모드를 자동으로 전환한다. 사용자가 "이 코드 왜 안 돼?"라고 물으면 GPT-5는 먼저 코드를 읽고, 실행 흐름을 시뮬레이션하고, 에러 원인을 단계적으로 추적한다. "오늘 날씨 어때?"라고 물으면 곧바로 짧게 답한다. 같은 모델이 맥락에 따라 사고 깊이를 조절하는 것이다.

멀티모달 처리도 한 단계 올라갔다. GPT-4o 수준의 이미지 이해에 더해, GPT-5는 이미지를 보고 실제 행동(파일 생성, API 호출, 코드 실행)까지 수행하는 에이전트 루프를 내장한다. 기존 o3 기반 에이전트처럼 별도 도구 연결 없이 기본 내장이다.

**주요 벤치마크 비교**

| 항목 | GPT-4o | o4-mini | GPT-5 |
|------|--------|---------|-------|
| MMLU (일반 지식) | 87.2% | 85.1% | 92.4% |
| MATH (수학 추론) | 76.6% | 93.4% | 96.1% |
| HumanEval (코딩) | 90.2% | 92.0% | 94.7% |
| SWE-bench (소프트웨어 엔지니어링) | 55.1% | 58.3% | 67.8% |

수치 자체도 올랐지만, 더 중요한 건 세 영역이 동일한 모델에서 나왔다는 점이다.

## 시장 영향

출시 첫날 ChatGPT Plus·Pro·Team 구독자에게 즉시 제공됐고, API는 별도 요금제로 운영된다. 가격은 기존 GPT-4o 대비 입력 토큰 당 약 2배 수준이지만, o3 기반 추론 모델보다는 30~40% 저렴하다. 복잡한 작업을 처리하면서도 o4-mini보다 비용이 낮아 기업 도입 문턱이 낮아졌다.

구글 Gemini 2.5 Ultra, 앤트로픽 Claude Opus 4.6과의 직접 경쟁 구도가 만들어졌다. 세 모델 모두 '추론 + 멀티모달 + 에이전트'를 단일 패키지로 묶는 방향으로 수렴하고 있다. AI 모델 시장의 차별화 포인트가 벤치마크 수치에서 실제 작업 완성도와 생태계 연동으로 이동하는 흐름이다.

국내에서는 Wrtn(뤼튼)·카카오·네이버 등 GPT API를 활용하는 서비스들의 모델 전환 여부가 주목된다.

## 병규의 한 줄

이번에 흥미로운 건 수치보다 설계 철학이다. OpenAI는 지금까지 "목적별로 최적화된 모델을 여러 개 내놓는" 전략을 택했다. GPT-5는 그 전략을 뒤집었다. 하나의 모델이 상황을 판단해 스스로 사고 방식을 바꾼다. 이게 가능해지면 "어떤 모델을 써야 하나"는 질문 자체가 사라진다. AI 인터페이스의 다음 단계는 모델 선택의 소멸이다.
