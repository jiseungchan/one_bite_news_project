9월 28일, 앤트로픽이 클로드 소네트 5.5를 출시했다. 클로드 5.5 패밀리의 두 번째 모델로, 빠른 속도와 낮은 비용이 필요한 일상 코딩·문서 작업용으로 설계됐다.

## 기존에는 어땠나

소네트 계열은 전통적으로 '오퍼스의 동생'이었다. 비용이 낮고 속도가 빠른 대신 복잡한 작업에서는 오퍼스에 미치지 못했다. 특히 코딩처럼 여러 단계를 이어나가는 장기 과제에서는 격차가 컸다. 소네트 5의 Terminal-Bench 4.0 점수가 10.3%였다는 사실이 그 한계를 잘 보여준다.

## 무엇이 달라졌나

이번 소네트 5.5의 Terminal-Bench 4.0 점수는 **70.6%**다. 소네트 5의 10.3%에서 한 번에 6배 이상 뛰었다. 수치 자체보다 흥미로운 건 이게 단순한 점수 개선이 아니라는 점이다.

| 벤치마크 | 소네트 5 | 소네트 5.5 |
|---------|---------|----------|
| Terminal-Bench 4.0 (코딩) | 10.3% | 70.6% |
| FrontierCode 1.1 | - | 46.2% |
| CursorBench 4.0 | - | 55.5% |
| GDPval-AA v2.1 (지식작업) | - | 1844 Elo |
| OSWorld 2.1 (컴퓨터 사용) | - | 80.1% |

지식 작업 벤치마크인 GDPval-AA v2.1에서 소네트 5.5가 기록한 1844 Elo는 오퍼스 5.5의 1846과 불과 2점 차이다. 소네트 계열이 오퍼스 계열과 사실상 같은 지식 처리 능력을 보인 건 이번이 처음이다.

앤트로픽 측이 공개한 이번 모델의 상징적 성과 하나가 있다. 바로 **포켓몬 레드(Pokémon Red) 클리어**다. 스크린샷만 보고 게임 전체를 완료한 첫 소네트 모델이다. 게임 클리어 자체가 중요한 게 아니라, 시각 정보만으로 수백 개의 의사결정을 연속적으로 이어가는 '장기 시각 추론(long-horizon visual reasoning)' 능력의 증거로 제시됐다.

속도와 효율도 개선됐다. 출력 생성 속도가 전작 대비 30% 이상 빨라졌고, 동일한 태스크를 처리하는 데 필요한 토큰 수가 30% 줄었다. 단가(per-token price)는 변하지 않았으므로, 실질적인 비용 절감 효과는 30%에 가깝다.

## 어디에 쓰이나

가격 구조는 입력 100만 토큰당 $2, 출력 100만 토큰당 $10으로 소네트 5와 동일하다. AWS, Google Cloud, Microsoft Azure 모두에서 `claude-sonnet-5-5` ID로 즉시 사용 가능하다.

안전 측면에서도 주목할 부분이 있다. 사이버보안 관련 안전장치를 오퍼스 5.5 수준으로 높였고, 'distillation attack'(모델 지식을 무단으로 추출하는 공격) 방지 기능도 새로 추가됐다.

## 병규의 한 줄

이번에 흥미로운 건 수치보다 설계 철학이다. 소네트와 오퍼스의 경계가 흐려지고 있다 — 앤트로픽은 "빠른 모델과 똑똑한 모델"이라는 이분법을 서서히 해체하고 있다. 가격은 '소네트', 성능은 '오퍼스'에 근접한 모델이 등장했다는 건, 앞으로의 경쟁이 모델 계열 간 성능 격차가 아니라 효율성과 특화 방향에서 벌어진다는 신호다.
