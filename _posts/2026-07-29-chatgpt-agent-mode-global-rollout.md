## 배경 — 'AI 어시스턴트'와 'AI 에이전트'는 무엇이 다른가?

ChatGPT가 2022년 등장했을 때, 이것은 **어시스턴트(assistant)**였다. 질문에 답하고, 글을 써주고, 코드를 설명해주는 대화 상대다. 핵심 한계는 명확했다 — ChatGPT는 스스로 행동할 수 없었다. 사용자가 대화 내용을 복사해 다른 앱에 붙여넣거나, 이메일을 직접 보내거나, 파일을 저장해야 했다.

**에이전트(agent)**는 다르다. 에이전트는 목표를 받으면 스스로 필요한 도구와 단계를 찾아 완료까지 처리한다. 예를 들어 "다음 주 도쿄 출장 준비해줘"라고 하면, 비행기 일정 검색 → 호텔 예약 → 일정표 생성 → 관련 담당자 이메일 초안 작성을 순서대로 수행한다. 중간에 사람이 개입할 필요가 없다.

오픈AI는 2025년부터 Operator(오퍼레이터)라는 이름으로 에이전트 모드 베타를 운영했다. 초기에는 ChatGPT Plus·Team·Enterprise 요금제 사용자 중 일부에게만 제공됐고, 지원되는 작업 유형도 제한적이었다.

## 전면 개방 — 무엇이 달라졌나?

이번 전면 개방의 핵심은 **세 가지 확대**다.

1. **접근 확대**: 무료 플랜 포함 모든 ChatGPT 사용자가 에이전트 기능 이용 가능 (무료 사용자는 월 일정 횟수 제한)
2. **도구 확대**: 기존 웹 검색·코드 실행에서 이메일 발송, 캘린더 관리, 클라우드 스토리지 연동, 외부 앱 API 호출까지 지원 도구 범위가 크게 넓어졌다
3. **언어 확대**: 에이전트 모드에서 한국어를 포함한 30개 언어로 작업 지시가 가능해졌다

| 항목 | 이전 Operator 베타 | 이번 전면 개방 |
|------|-----------------|--------------|
| 이용 대상 | 유료 플랜 일부 | 전 사용자 |
| 지원 작업 | 웹 검색·코드 실행 | 이메일·캘린더·파일·외부 앱 포함 |
| 한국어 지원 | 제한적 | 완전 지원 |
| 동시 실행 | 1개 작업 | 최대 5개 병렬 |

## 실제로 어떻게 쓰이나?

오픈AI가 공개한 에이전트 사용 사례 중 주목할 만한 것들이다.

- **마케팅 담당자**: "지난달 경쟁사 신제품 발표 내용 정리해서 팀장한테 월간 요약 이메일 보내줘" → 웹 조사 + 문서 작성 + 이메일 발송 자동화
- **스타트업 창업자**: "VC(벤처캐피탈) 투자자 5명 찾아서 각자 관심 분야에 맞춘 콜드 이메일(첫 연락 메일) 초안 만들어줘" → 리서치 + 개인화 작성
- **개인 사용자**: "이번 달 구독 서비스 중 3개월 이상 안 쓴 것 찾아서 해지 이메일 초안 만들어줘" → 연동된 이메일 분석 + 초안 생성

## 국내 시장 반응

국내 IT 업계의 반응은 경계와 기대가 엇갈린다. 카카오·네이버 등 국내 AI 플랫폼 기업들은 이미 자체 에이전트 기능 개발을 가속화하고 있다. 챗GPT 에이전트가 한국 시장에서도 본격 경쟁자로 부상한 만큼, 국내 서비스와의 깊은 연동(카카오톡, 토스, 네이버 카페 등)을 강점으로 내세울 것으로 예상된다.

## 병규의 한 줄

에이전트 모드 전면 개방이 의미하는 건 단순히 ChatGPT 기능이 늘었다는 게 아니다. AI가 '대화 상대'에서 '실제로 일하는 존재'로 전환하는 순간, 우리가 AI를 어떻게 쓰는지가 아니라 **무엇을 AI에게 맡기느냐**가 핵심 역량이 된다. 지시를 잘 내리는 능력이 코딩보다 중요한 스킬이 되는 시대, 이제 본격적으로 시작됐다.
