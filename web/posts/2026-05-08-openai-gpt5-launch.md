## 한 줄 요약
> GPT-5는 '더 잘 대답하는 AI'가 아니라 '스스로 작업을 완수하는 AI'로의 방향 전환을 공식화한 모델이다.

## 리드 — 왜 지금 이게 중요한가?

OpenAI가 GPT-5를 정식 출시했다. 이번 모델은 기존 GPT-4o 대비 추론 능력과 코딩 성능을 전면 강화했으며, 특히 에이전트(agent — 사용자 지시 없이 스스로 여러 단계의 작업을 수행하는 AI 기능) 기능을 기본으로 내장했다. 단순히 질문에 답하는 수준을 넘어, 인터넷 검색·코드 실행·파일 작업을 스스로 순서대로 처리하는 구조다.

## 배경 — 기존에는 어땠나?

GPT-3.5가 처음 등장한 2022년 말부터 GPT-4에 이르기까지, 대화형 AI의 주된 진화 방향은 '더 정확한 대답'이었다. 벤치마크 점수가 오르고 환각(hallucination — AI가 사실이 아닌 내용을 사실처럼 답하는 현상) 비율이 줄었다. 하지만 근본적인 사용 방식은 바뀌지 않았다. 인간이 질문하면 AI가 답하는 구조였다.

2025년부터 업계는 이 구조의 한계를 실감했다. 아무리 정확한 답변을 줘도, 사용자가 그 답변을 가지고 직접 실행해야 한다면 자동화의 효율은 절반에 그친다. 이 맥락에서 에이전트형 AI가 새로운 기준이 됐다. 구글 Gemini 1.5 Pro, Anthropic Claude 3.5 Sonnet 모두 에이전트 기능 강화를 핵심 차별점으로 내세웠다.

## 핵심 — 무엇이 다른가?

GPT-5의 에이전트 통합은 이전 버전과 구조적으로 다르다. GPT-4o에서도 플러그인이나 API 연동을 통해 일부 자동화가 가능했지만, 이는 외부 도구를 '붙이는' 방식이었다. GPT-5는 에이전트 실행 엔진이 모델 내부에 통합돼 있다.

작동 방식을 단계로 나누면 이렇다:

1. **목표 해석**: 사용자의 자연어 지시를 세부 하위 작업으로 분해한다
2. **도구 선택**: 웹 검색·코드 실행·파일 편집 중 각 단계에 적합한 도구를 자동으로 결정한다
3. **실행 및 검증**: 각 단계를 실행하고 결과를 스스로 검토한 뒤 다음 단계로 넘어간다
4. **보고**: 전체 작업 완료 후 사용자에게 요약 결과를 전달한다

| 구분 | GPT-4o | GPT-5 |
|------|--------|-------|
| 에이전트 기능 | 외부 플러그인 연동 | 모델 내부 통합 |
| 멀티스텝 자동화 | 수동 개입 필요 | 자율 실행 |
| 코딩 성능 | SWE-bench 기준 이전 세대 | 전면 강화 (공식 발표) |
| 멀티모달 | 이미지 인식 | 이미지·오디오·문서 처리 |

## 시장 영향 — 어디에 쓰이나?

- **개발·코딩**: 코드 작성에서 테스트·디버깅까지 에이전트가 자율 처리하는 시나리오가 현실화됐다
- **업무 자동화**: 이메일 정리·일정 조율·보고서 초안 작성을 사람 없이 연속 처리 가능
- **데이터 분석**: 원시 데이터 파일을 받아 시각화 자료까지 자동 생성하는 파이프라인 구축 가능

GPT-5는 ChatGPT Plus 및 API를 통해 순차 공개된다. 기업용 ChatGPT Enterprise에는 에이전트 기능이 우선 제공될 예정이다.

## 병규의 한 줄

이번 GPT-5에서 흥미로운 건 성능 수치보다 '에이전트를 모델 밖이 아닌 안으로 가져왔다'는 구조적 결정이다. 이 선택은 OpenAI가 AI를 도구가 아닌 실행 주체로 정의한다는 신호다.
