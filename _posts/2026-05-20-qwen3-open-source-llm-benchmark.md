## 한 줄 요약
> Qwen3의 등장은 '오픈소스는 GPT-4급에 못 미친다'는 통념을 깼다. 더 중요한 건, MoE 구조 덕분에 추론 비용이 종전 동급 모델 대비 3분의 1 수준이라는 점이다.

## 리드 — 왜 지금 이게 중요한가?

알리바바 클라우드가 공개한 오픈소스 언어 모델 Qwen3(큰원3)가 업계의 기준점으로 쓰이는 MMLU(대규모 멀티태스크 언어이해 벤치마크), HumanEval(코딩 정확도 평가), MATH(수학 추론 평가)에서 OpenAI GPT-4o를 상회하는 결과를 기록했다고 인공지능신문이 20일 보도했다. 가중치(weights — 모델의 학습 결과가 저장된 파라미터 값)를 오픈소스로 공개했기 때문에 누구나 자체 서버에서 실행·수정할 수 있다.

오픈소스 AI 진영에서 이 정도 수준의 성능 역전은 2025년 Meta Llama 3이 클로즈드 모델과 격차를 좁힌 이후 처음이다.

## 배경 — 기존에는 어땠나?

오픈소스 LLM(대규모 언어 모델)은 2023~2024년 내내 'GPT-4급에는 못 미친다'는 벽이 있었다. Meta의 Llama 2, Mistral 7B, Falcon 등이 연이어 나왔지만, 복잡한 추론·코딩·수학 과제에서는 GPT-4와 눈에 띄는 격차가 있었다. 기업들이 오픈소스를 택하면 비용을 아끼는 대신 성능을 포기하는 트레이드오프가 명확했다.

2025년 들어 Meta Llama 3, Mistral Large, Qwen 2.5가 격차를 좁혔지만 '추월'까지는 이르지 못했다. Qwen 시리즈는 중국어 처리에 강점을 보였고, 영어 범용 벤치마크에서는 여전히 GPT-4o 아래에 머물렀다.

## 핵심 — 무엇이 다른가?

Qwen3의 핵심 구조는 MoE(Mixture of Experts — 입력에 따라 전체 파라미터 중 일부 전문가 네트워크만 활성화하는 구조)다. 전체 파라미터는 235B(2,350억 개)이지만, 실제 추론 시 활성화되는 파라미터는 약 22B 수준이다. 마치 병원에서 모든 의사가 모든 환자를 보는 게 아니라 전문과에 맞게 배분하는 것과 같은 원리다.

이 구조의 효과는 두 가지다.

**성능**: 전체 파라미터 수가 크기 때문에 다양한 도메인 지식을 담을 수 있어 MMLU에서 89.4%를 기록했다. GPT-4o의 공개 수치 88.7%를 0.7%포인트 앞선다.

**비용**: 실제 추론 시 활성화되는 파라미터가 22B 수준이므로, 동일 수준의 응답을 생성하는 데 필요한 컴퓨팅이 완전 밀집 모델(dense model — 모든 파라미터가 항상 활성화되는 기존 구조) 대비 3분의 1에 불과하다.

| 항목 | GPT-4o | Qwen3 (235B MoE) |
|------|--------|------------------|
| 모델 공개 여부 | 클로즈드 | 오픈소스 |
| MMLU 점수 | 88.7% | 89.4% |
| 활성 파라미터 | 비공개 | 약 22B |
| 추론 비용 | API 과금 | 자체 배포 가능 |
| 한국어 지원 | 우수 | 중·영어 최적화, 한국어 준수 |

## 시장 영향 — 어디에 쓰이나?

- 클라우드 API 비용 절감을 노리는 스타트업과 중소기업들이 즉시 채택 가능한 환경이 만들어졌다
- 코딩 보조 분야에서 HumanEval 점수가 GPT-4o를 넘어선 점이 특히 주목된다. GitHub Copilot 대체재로 Qwen3 기반 제품들이 나올 가능성이 높다
- 국내에서는 KT, LG CNS 등 자체 AI 인프라를 가진 기업들이 Qwen3를 파인튜닝해 도메인 특화 모델을 만드는 방향을 검토 중인 것으로 알려졌다
- 오픈소스 경쟁의 승자가 중국 기업(알리바바)이 된 점은 미국-중국 AI 경쟁 구도에서 새로운 전선이 형성됐음을 의미한다

## 병규의 한 줄

이번에 흥미로운 건 벤치마크 수치보다 MoE 구조가 '성능 vs 비용' 트레이드오프를 사실상 해소하기 시작했다는 점이다. 지금까지 오픈소스 선택은 '저렴하지만 부족한 것'을 선택하는 행위였는데, Qwen3 이후로는 그 전제가 흔들린다.
