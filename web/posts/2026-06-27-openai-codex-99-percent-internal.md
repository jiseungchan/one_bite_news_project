## 99%라는 숫자

OpenAI 사내에서 AI가 생성하는 출력 토큰의 99% 이상이 코덱스(Codex)에서 나온다. 나머지 1%가 ChatGPT 같은 대화형 인터페이스다. 이 숫자가 말하는 건 간단하다: 오늘날 OpenAI 직원들에게 AI란 '질문하면 답해주는 도구'가 아니라 '일을 맡기면 알아서 해결하는 에이전트'다.

## 코덱스(Codex)가 뭔가

코덱스는 OpenAI가 개발한 코딩 특화 AI 에이전트다. 단순히 코드를 제안하는 자동완성 도구를 넘어, 복잡한 소프트웨어 프로젝트 전반을 자율적으로 계획하고 실행한다. 에이전트(Agent)란 단일 질문-답변 방식이 아닌, 목표를 받아 여러 단계의 작업을 스스로 수행하는 AI 시스템을 뜻한다.

## 수치들이 보여주는 것

2026년 5월 기준, OpenAI 내부 사용자 데이터를 보면 패턴이 뚜렷하다.

- **80.6%**: 사람이 수행하면 30분 이상 걸릴 작업을 코덱스에 최소 한 번 위임한 사용자 비율
- **70.2%**: 1시간 이상 소요되는 작업을 맡긴 비율
- **25.6%**: 8시간, 즉 사람 하루치 업무를 위임한 비율
- **상위 1% 사용자**: 하루 평균 60시간 이상의 에이전트 작업을 병렬로 수행 중

60시간은 착오가 아니다. 에이전트 여러 개를 동시에 돌리면 가능한 수치다. 한 사람이 동시에 여러 프로젝트를 진행시키는 것, 이게 지금 OpenAI 사내에서 일어나는 일이다.

## 무엇이 달라지고 있나

기존 업무용 챗봇의 패턴은 이렇다: 질문 → 답변 → 사람이 결과물 활용. 사람이 여전히 중심이고, AI는 보조다.

코덱스 방식은 다르다: 목표 전달 → 에이전트가 계획·실행·완성. 사람은 결과를 확인하거나 방향을 수정한다. AI가 실행 주체로 올라선다.

| 구분 | 챗봇 모델 | 에이전트 모델 |
|------|----------|-------------|
| 상호작용 방식 | 질문-답변 반복 | 목표 위임 후 자율 실행 |
| 사람의 역할 | 매 단계 지시 | 방향 설정·결과 검토 |
| 작업 시간 | 단발성 (분 단위) | 장시간 (시간~일 단위) |
| AI 출력 형태 | 텍스트 답변 | 코드·파일·결과물 |

## 이번에 흥미로운 건

'99%'가 보여주는 건 기술 변화보다 행동 변화다. OpenAI 직원들이 코덱스를 주력 도구로 선택했다는 건 이게 실제로 더 효율적이라는 뜻이다. 아직 실험 단계가 아니라는 것. 이미 일하는 방식이 바뀌었다는 것. 이 변화가 OpenAI 밖에서도 일어나는 것은 시간 문제다.
