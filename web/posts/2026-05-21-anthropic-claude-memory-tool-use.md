## 한 줄 요약
> 클로드가 이제 "지난번에 말씀하셨는데요"라고 할 수 있게 됐다 — AI 어시스턴트와 AI 에이전트의 경계가 흐려지는 순간.

## 리드 — 왜 지금 이게 중요한가?

앤트로픽이 클로드 AI에 영구 메모리(persistent memory — 대화 세션이 종료된 후에도 정보를 유지하는 기능) 기능을 정식 출시했다. 이제 클로드는 "저번 주에 말씀하신 프로젝트 방향대로 진행해드릴까요?"라고 스스로 물을 수 있다. 단순해 보이지만, 이 기능이 의미하는 건 크다. AI 어시스턴트가 도구에서 협업자로 이동하는 데 필요한 핵심 조건 중 하나가 '기억'이기 때문이다.

## 배경 — 기존에는 어땠나?

지금까지 대부분의 AI 어시스턴트는 대화 세션(session — 하나의 대화창을 열고 닫는 단위)이 끝나면 모든 맥락을 잃었다. 매번 새 창을 열면 처음부터 다시 시작해야 했다. 사용자는 반복적으로 "나는 마케터야, 스타트업에서 일하고, 영어보다 한국어를 선호해" 같은 배경 정보를 다시 입력해야 했다.

이 문제를 완화하기 위해 일부 서비스는 "시스템 프롬프트"나 "커스텀 지시" 기능을 제공했다. 하지만 이건 사용자가 직접 설정해야 하는 정적인 데이터였다. 대화 중에 나온 정보, "오늘은 A 방향으로 결정했다" 같은 내용은 다음 세션에서 증발했다.

ChatGPT는 2024년 초부터 메모리 기능을 일부 사용자에게 제공해왔다. 그러나 무엇을 기억하고 무엇을 잊을지 제어하는 UI가 복잡하다는 피드백이 많았고, 기억 용량에도 한계가 있었다.

## 핵심 — 무엇이 다른가?

앤트로픽이 구현한 방식의 특이점은 메모리 저장과 호출 방식에 있다. 클로드는 대화 중 기억할 만한 정보를 식별하면, 외부 저장소(사용자별 벡터 DB — 의미 기반 검색이 가능한 데이터베이스 형태)에 자동으로 기록한다. 다음 대화에서 관련 맥락이 필요하면 이 저장소를 검색해 불러온다.

| 항목 | 기존 방식 | 클로드 영구 메모리 |
|------|---------|-----------------|
| 기억 단위 | 세션 내 컨텍스트 창 | 세션 초월 영구 저장 |
| 기억 방식 | 수동 설정 | 대화 중 자동 감지·저장 |
| 검색 방식 | 없음 | 의미 기반 벡터 검색 |
| 사용자 제어 | 제한적 | 저장 항목 확인·삭제 가능 |

앤트로픽은 프라이버시 설계에도 신경을 썼다. 사용자는 무엇이 기억됐는지 목록으로 확인할 수 있고, 항목별로 삭제하거나 전체 메모리를 초기화할 수 있다. 또한 메모리 저장을 아예 끄는 옵션도 있다.

이 기능은 현재 Claude Pro(월 $20) 및 Claude Team 플랜 사용자부터 순차 적용되며, API 접근도 별도로 제공된다.

## 시장 영향 — 어디에 쓰이나?

기업 환경에서 활용 가능성이 높다. 특히 반복적인 맥락 공유가 필요한 업무에서 효율이 달라진다.

- **법무·컨설팅**: 클라이언트별 맥락(계약 구조, 담당자, 이전 결정)을 누적 관리
- **소프트웨어 개발**: 프로젝트 아키텍처 결정 사항, 팀 컨벤션을 기억하고 조언
- **마케팅 기획**: 브랜드 톤, 타깃 고객, 이전 캠페인 히스토리를 자동 참조

개인 사용자 입장에서는 매번 맥락을 재설명하는 피로감이 줄어든다. 다만 "AI가 내 정보를 어떻게 저장하고 사용하는가"에 대한 신뢰 문제는 여전히 사용자마다 다르게 반응할 것으로 보인다.

## 병규의 한 줄

이번에 흥미로운 건 기능 자체보다 타이밍이다. OpenAI의 Codex가 코딩 에이전트로 실행 능력을 확장하는 시점에, 앤트로픽은 기억 능력을 강화했다. "무엇을 할 수 있느냐"보다 "얼마나 나를 이해하느냐"라는 경쟁 축이 추가된 것인데, 장기적으로 사용자 락인(lock-in — 특정 서비스에 의존하게 만드는 효과)에서 결정적인 차별점이 될 수 있다.
