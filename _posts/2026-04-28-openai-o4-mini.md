## 한 줄 요약
> '추론은 비싸다'는 공식을 OpenAI가 스스로 깨뜨렸다 — o4-mini는 가격 파괴와 성능 유지를 동시에 주장한다.

## 리드 — 왜 지금 이게 중요한가?

OpenAI가 2026년 4월 28일 새 추론 모델 o4-mini를 공개했다. 기존 o3-mini 대비 추론 비용이 10분의 1 수준이다. 추론 모델(reasoning model — 복잡한 문제를 단계별로 나눠 생각하는 AI)은 지금까지 높은 연산 비용 때문에 일반 기업이 대규모로 도입하기 어려웠다. o4-mini는 그 장벽을 직접 겨냥했다.

## 배경 — 기존에는 어땠나?

OpenAI의 추론 모델 계보는 o1에서 시작됐다. o1은 수학·코딩 문제를 기존 GPT-4보다 훨씬 잘 풀었지만, 응답 한 번에 드는 비용이 GPT-4o의 3~5배였다. o3로 세대를 업그레이드하면서 성능은 크게 올랐지만 비용도 그대로 높은 수준을 유지했다.

결과적으로 추론 모델은 "어렵고 중요한 작업에 가끔 쓰는 프리미엄 도구"에 머물렀다. 대량 문서 처리, 실시간 고객 응대, 코드 리뷰 자동화처럼 요청 수가 많은 용도에는 비용 부담이 너무 컸다.

## 핵심 — 무엇이 다른가?

o4-mini가 비용을 낮출 수 있었던 핵심은 **추론 깊이의 동적 조절**이다. 모든 질문에 똑같이 깊이 생각하지 않고, 문제 난이도에 따라 "생각하는 양"을 자동으로 줄인다.

| 항목 | o3-mini | o4-mini |
|------|---------|---------|
| 입력 토큰 비용 | 기준 | 약 1/10 |
| 출력 토큰 비용 | 기준 | 약 1/10 |
| 수학 벤치마크 (AIME) | 유지 수준 | 동등 이상 |
| 응답 속도 | 기준 | 동등 이상 |
| 컨텍스트 창 | 128K | 128K |

동작 방식을 단순하게 설명하면, 마치 숙련된 계산원이 "잔돈 계산은 암산, 복잡한 세금 계산은 계산기"를 구분해서 쓰는 것처럼, o4-mini는 문제 복잡도를 먼저 파악하고 그에 맞는 추론 단계 수를 배정한다.

API 접근은 기존 OpenAI API 키로 즉시 가능하며, ChatGPT Plus·Team 구독자에게도 순차 제공된다.

## 시장 영향 — 어디에 쓰이나?

- 코딩 자동화: 코드 리뷰, 버그 탐지, 리팩토링 제안에 대량 적용 가능
- 문서 처리: 계약서·보고서 분석을 기업 규모로 운영할 수 있는 수준
- 교육 플랫폼: 학생별 맞춤 문제 해설 서비스의 단가 현실화
- 국내 영향: 네이버·카카오·LG 등 AI 플랫폼 기업의 API 채택 비용 구조가 바뀔 수 있다

Anthropic의 Claude Haiku, Google의 Gemini Flash와 함께 "저비용 추론 모델" 시장에서 3파전 구도가 형성됐다.

## 병규의 한 줄

이번 o4-mini에서 흥미로운 건 성능 수치보다 전략적 신호다. OpenAI가 고성능 프리미엄 라인(o3, o3 Pro)을 유지하면서 동시에 저가형 추론 라인을 내려놓은 것은, '추론 AI = 비싼 것'이라는 시장 인식을 OpenAI 스스로 먼저 깨겠다는 의지처럼 읽힌다.
