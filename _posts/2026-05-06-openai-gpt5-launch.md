## 한 줄 요약
> GPT-5는 성능이 오른 것이 아니라, AI가 '작업을 스스로 계획하는 방식' 자체가 바뀐 모델이다.

## 리드 — 왜 지금 이게 중요한가?

OpenAI가 2026년 5월 GPT-5를 공식 출시했다. 발표 자리에서 샘 올트먼 CEO는 "지금까지 만든 모델 중 가장 지능적"이라는 말을 썼다. 이 표현은 OpenAI가 항상 쓰는 수식어처럼 들리지만, 이번엔 맥락이 다르다. GPT-5는 단순히 파라미터(모델 내부 가중치 수)를 늘린 버전이 아니라, 추론과 실행을 동시에 처리하는 구조적 변화를 담고 있다.

## 배경 — 기존에는 어땠나?

GPT-4o 시리즈까지 OpenAI 모델의 기본 구조는 '입력을 받아 한 번에 출력을 내놓는' 방식이었다. 복잡한 수학 문제나 긴 코드 작업을 처리할 때 정답을 한 번에 생성하려다 보니 중간 추론 과정에서 오류가 쌓였다. 이를 보완하기 위해 o1·o3 같은 추론(reasoning) 모델 계열이 별도로 운영됐다.

문제는 이 두 계열이 사실상 분리돼 있었다는 점이다. o3는 깊이 생각하는 대신 응답이 느리고 비용이 높았다. GPT-4o는 빠르지만 복잡한 작업에서 한계가 명확했다. 사용자는 작업 유형에 따라 모델을 직접 골라야 했고, 이 선택 자체가 허들이었다.

## 핵심 — 무엇이 다른가?

GPT-5의 핵심 변화는 추론(reasoning) 기능이 모델 안에 통합됐다는 점이다. 별도의 o-시리즈 모델 없이, GPT-5 하나가 작업 복잡도에 따라 스스로 '얼마나 깊이 생각할지'를 조절한다. 간단한 질문에는 빠르게 답하고, 복잡한 코딩이나 논증 작업에는 내부적으로 여러 단계를 거쳐 처리한다.

| 항목 | GPT-4o | GPT-5 |
|------|--------|-------|
| 추론 방식 | 단일 패스 생성 | 적응형 멀티스텝 추론 |
| 모델 전환 필요 | 작업별 수동 선택 | 단일 모델 자동 조절 |
| 멀티모달 처리 | 텍스트·이미지 | 텍스트·이미지·오디오·비디오 |
| 컨텍스트 창 | 128K 토큰 | 256K 토큰 |

멀티모달(여러 형식의 데이터를 동시에 처리하는 능력) 범위도 넓어졌다. 기존 텍스트·이미지 중심에서 오디오와 영상 이해까지 하나의 모델로 처리한다.

## 시장 영향 — 어디에 쓰이나?

OpenAI는 GPT-5를 ChatGPT Plus·Pro 구독자에게 우선 제공하고, API 접근은 단계적으로 확대한다고 밝혔다. 기업용 시장에서는 코딩 자동화, 계약서 분석, 멀티모달 고객 응대 등의 활용이 즉시 가능해질 전망이다.

특히 코딩 벤치마크인 SWE-bench(소프트웨어 엔지니어링 문제 풀이 능력 측정 기준)에서 전작 대비 큰 폭의 향상이 보고됐다. 구체적 수치는 OpenAI 공식 발표 이후 확정된다.

## 병규의 한 줄

이번에 주목하고 싶은 건 기능 목록이 아니라 설계 방향이다. '추론 모델을 따로 쓰세요'에서 '알아서 판단합니다'로 바뀐 것은 작은 편의 개선이 아니라, AI가 사용자에게 얼마나 많은 판단을 위임받을 것인가에 대한 답이 달라진 것이다.
