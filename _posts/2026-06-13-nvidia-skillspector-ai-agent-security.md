## 한 줄 요약
> AI 에이전트가 설치하는 '스킬' 중 4개에 1개꼴로 보안 취약점이 있다는 연구 결과와 함께, NVIDIA가 이를 자동 탐지하는 도구를 오픈소스로 공개했다.

## 리드 — 왜 지금 이게 중요한가?

Claude Code, Gemini CLI 같은 AI 코딩 에이전트들이 외부 스킬(플러그인처럼 에이전트가 설치해 기능을 확장하는 패키지)을 점점 더 많이 사용하고 있다. NVIDIA가 42,447개의 스킬을 분석했더니 26.1%에서 취약점이 발견됐고, 5.2%는 악의적 의도 가능성이 높은 것으로 나타났다. AI 에이전트 생태계가 빠르게 성장하는 지금, 사람이 일일이 확인하지 않아도 스킬을 믿고 설치해왔던 관행에 경고등이 켜진 셈이다.

## 배경 — 기존에는 어땠나?

스마트폰 앱을 설치할 때 우리는 앱스토어의 검토를 믿는다. 하지만 AI 에이전트 스킬 마켓플레이스는 아직 그런 체계가 정착되지 않았다. 에이전트는 설치된 스킬을 기본적으로 신뢰하며 실행하는 구조라, 악성 스킬 하나가 시스템 전체에 접근권을 얻을 수 있다.

문제는 스킬이 단순한 텍스트 설명이 아니라 실행 가능한 코드를 포함한다는 점이다. 연구 결과에 따르면 실행 가능한 스크립트가 포함된 스킬은 그렇지 않은 스킬보다 취약점 발생 확률이 2.12배 높다. 개발자가 선의로 만든 스킬이어도 `exec`, `eval`, `subprocess` 같은 위험 함수 호출이 무심코 포함되는 경우가 많다.

## 핵심 — 무엇이 다른가?

NVIDIA가 공개한 **SkillSpector**는 스킬을 설치하기 전에 자동으로 안전 여부를 판단해주는 도구다.

분석은 2단계로 진행된다.

**1단계: 정적 분석** — 64개의 취약점 패턴을 기반으로 정규식과 AST(추상 구문 트리 — 코드를 구조적으로 분해한 표현 방식) 분석을 수행한다. 위험 함수 호출, 프롬프트 인젝션(악의적 명령어를 AI에 몰래 주입하는 공격), 데이터 유출 패턴 등 16개 카테고리를 빠르게 훑는다.

**2단계: LLM 의미론적 분석** — 1단계에서 의심스러운 항목이 발견되면 LLM이 코드의 맥락을 파악해 거짓 양성을 걸러내고 인간이 읽을 수 있는 설명을 제공한다. OpenAI, Anthropic, NVIDIA 자체 API 모두 연동 가능하다.

| 항목 | 기존 방식 | SkillSpector |
|------|----------|-------------|
| 취약점 탐지 | 수동 코드 리뷰 | 자동 64개 패턴 검사 |
| CVE 조회 | 별도 확인 필요 | OSV.dev 실시간 연동 |
| 위험도 판단 | 주관적 | 0~100 점수 자동 산출 |
| 출력 형식 | 없음 | JSON, Markdown, SARIF |

위험 점수는 0~100 범위로, 51점 이상이면 설치 금지 권고가 나온다.

## 시장 영향 — 어디에 쓰이나?

- **대상 스킬 형식**: Git 저장소, URL, zip 파일, 단일 파일 등 다양한 형식 지원
- **탐지 카테고리 예시**: 프롬프트 인젝션, 권한 상승, 공급망 공격(Supply Chain Attack — 신뢰된 패키지에 악성코드를 심는 방식), MCP 도구 중독(Model Context Protocol — AI 에이전트가 외부 도구를 사용하는 표준 프로토콜)
- **라이선스**: Apache 2.0 오픈소스, GitHub 공개 첫날 +809 별
- **주요 영향 직군**: AI 에이전트를 도입하는 기업 보안팀, AI 개발자, 에이전트 마켓플레이스 운영자

## 병규의 한 줄

이번에 흥미로운 건 수치보다 이 도구가 전제하는 가정이다. AI 에이전트가 스킬을 "믿고 쓴다"는 지금의 구조는 초기 인터넷이 악성코드를 "믿고 실행"하던 시절과 닮았다. SkillSpector는 그 생태계에 안티바이러스가 처음 등장하는 순간처럼 보인다.
