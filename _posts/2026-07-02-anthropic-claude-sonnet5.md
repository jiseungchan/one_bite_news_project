## 한 줄 요약
> 앤트로픽이 소네트 5를 공개하며 "최상위 오퍼스 수준의 에이전트 성능을 소네트 가격에 제공하겠다"는 선언을 내놨다 — 성능과 비용 사이에서 기업들이 겪던 딜레마를 정면으로 허무는 발표다.

## 리드 — 왜 지금 이게 중요한가?
앤트로픽(Anthropic)이 새 모델 클로드 소네트 5(Claude Sonnet 5)를 공개하면서 "오퍼스급 에이전트 성능"을 훨씬 낮은 비용으로 제공하겠다고 밝혔다. AI 에이전트(Agent — 단순 질답이 아닌, 검색·코드 실행·파일 관리 등 다단계 작업을 자율적으로 수행하는 AI)가 기업용 AI의 핵심으로 부상한 시점에, 가격과 성능의 벽을 동시에 낮추겠다는 선언이어서 업계가 주목하고 있다.

## 배경 — 기존에는 어땠나?
앤트로픽의 모델 라인업은 크게 세 등급으로 나뉘어 왔다. 최상위 오퍼스(Opus)는 복잡한 추론과 다단계 자율 작업에 가장 강하지만, 그만큼 사용 비용이 높다. 중간급 소네트(Sonnet)는 성능과 비용 사이의 균형을 맡아왔고, 가장 저렴한 하이쿠(Haiku)는 단순·반복 작업에 쓰였다.

이 구조의 핵심 문제는 에이전트 작업에서 드러났다. 웹 검색부터 API 호출, 코드 작성, 결과 검증까지 여러 단계를 자율로 처리하는 에이전트 파이프라인(Pipeline — 여러 AI 처리 단계를 연결한 자동화 흐름)에는 오퍼스급 추론 능력이 필요하다. 그런데 오퍼스를 에이전트에 대규모로 투입하면 비용이 급격히 불어나고, 소네트를 쓰면 복잡한 다단계 작업에서 실수가 잦아진다. 기업들은 이 딜레마 사이에서 줄타기를 해왔다.

## 핵심 — 무엇이 다른가?
클로드 소네트 5는 이 딜레마를 정면으로 뚫겠다는 모델이다. 앤트로픽의 핵심 주장은 두 가지다.

**오퍼스급 에이전트 성능**: 멀티스텝 추론(Multi-step reasoning — 문제를 잘게 나눠 순서대로 해결하는 능력)과 도구 사용(Tool use — 외부 API, 검색 엔진, 코드 실행기 등을 AI가 직접 호출하는 기능)에서 기존 최상위 모델과 동등한 수준을 목표로 설계됐다는 점이다.

**소네트 가격대 유지**: 성능을 높이면서도 비용 등급을 중간선에 묶겠다는 약속이다. 에이전트를 실제 서비스에 수천, 수만 번 호출하는 기업 입장에서 오퍼스급 성능을 소네트 비용에 활용할 수 있다면 경제성의 방정식이 완전히 달라진다.

마치 비즈니스석 서비스를 이코노미 운임에 받는 구조와 같은 개념이다. 품질을 타협하지 않고도 규모 확장이 가능해진다.

| 항목 | 기존 구조 | 소네트 5 목표 |
|------|----------|-------------|
| 에이전트 성능 | 오퍼스 필요 | 소네트 5로 동등 |
| 사용 비용 | 오퍼스 요금 | 소네트 가격대 |
| 확장성 | 비용 급증 | 대규모 배포 가능 |
| 포지셔닝 | 성능·비용 二擇一 | 두 마리 토끼 |

## 시장 영향 — 어디에 쓰이나?
- 코드 작성부터 테스트·배포까지 자동화하는 소프트웨어 개발 에이전트
- 고객 응대·데이터 분석·보고서 작성을 처리하는 기업용 자동화 파이프라인
- 웹 리서치와 정보 수집을 수행하는 AI 리서치 에이전트
- 복잡한 멀티에이전트(Multi-agent — 여러 AI가 협업해 하나의 과제를 처리하는 구조) 워크플로우

에이전트 비용 절감이 사업 생존의 문제인 SaaS 스타트업부터 대규모 AI 전환을 추진하는 대기업까지, 에이전트를 실제로 쓰는 모든 팀이 직접 영향권에 들어온다.

## 병규의 한 줄
이번에 흥미로운 건 "에이전트는 비싸도 된다"는 업계 암묵적 상식을 앤트로픽이 설계 철학으로 뒤집었다는 점이다. 성능의 민주화가 채팅 완성도가 아니라 에이전트 경제성에서 먼저 실현된 셈이다.
