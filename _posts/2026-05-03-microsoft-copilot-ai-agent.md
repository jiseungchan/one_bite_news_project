## 배경 — AI가 '도구' 안에 갇혀 있던 시절

지금까지 PC에서 AI를 쓰는 방식은 단순했다. ChatGPT 창을 열거나 Copilot 사이드바를 불러와 질문하고, 그 답을 복사해서 다른 앱에 붙여넣는다. AI가 답을 줄 수는 있어도 직접 행동하지는 않았다.

마이크로소프트 Copilot+ PC는 2024년 처음 등장했을 때 강력한 NPU(신경망 처리 장치, AI 연산을 전담하는 칩)를 탑재해 온디바이스 AI를 가능하게 했다. 하지만 실제 사용자들이 느낀 차별점은 크지 않았다. "Recall(PC 활동을 기억해 검색하는 기능)은 개인정보 우려 때문에 비활성화됐고, 나머지 기능은 기존 PC와 큰 차이가 없다"는 평가가 지배적이었다.

이번 업데이트는 그 한계를 정면으로 돌파하려는 시도다.

## 핵심 — AI가 PC를 직접 조작한다

마이크로소프트가 발표한 새 기능의 핵심은 **에이전트(agent, 스스로 목표를 정하고 단계적으로 실행하는 AI)가 Windows 운영체제 전반에 걸쳐 실제 작업을 수행**한다는 점이다.

작동 방식은 이렇다.

1. 사용자가 자연어로 지시한다. ("지난 주에 받은 프로젝트 제안서 초안 정리해서 팀에 보내줘")
2. Copilot 에이전트가 파일 탐색기에서 관련 문서를 검색한다.
3. Word에서 요약본을 자동 생성한다.
4. Outlook에서 수신인을 찾아 이메일 초안을 작성한다.
5. 사용자의 최종 확인 후 발송한다.

**기존 Copilot vs 에이전트 통합 Copilot+ 비교**

| 항목 | 기존 Copilot | 에이전트 통합 Copilot+ |
|------|-------------|----------------------|
| 동작 방식 | 질문 → 답변 | 지시 → 자율 실행 |
| 앱 연동 | 수동 복사·붙여넣기 | 앱 간 자동 이동 |
| 파일 접근 | 별도 업로드 필요 | PC 내 파일 직접 탐색 |
| 외부 서비스 | 미연동 | 캘린더·이메일·Teams 연동 |

특히 주목할 만한 것은 **오프라인 동작** 지원이다. Copilot+ PC에 탑재된 NPU가 핵심 추론 작업을 클라우드 없이 처리하기 때문에, 인터넷 연결 없이도 기본 에이전트 기능이 동작한다. 기업 보안 환경에서 클라우드 AI 사용을 제한했던 곳에도 도입 가능해진다.

## 시장 영향 — PC 시장 판도가 바뀔 수 있다

- Copilot+ PC 전 라인업(서피스, OEM 파트너 포함)에 순차 업데이트로 제공
- 퀄컴 스냅드래곤 X 시리즈, 인텔 Core Ultra 200V 계열, AMD Ryzen AI 300 시리즈 대상
- 기업용 Microsoft 365 Copilot 구독자는 확장 에이전트 기능 추가 제공
- 개인 사용자는 무료 기본 에이전트, 고급 기능은 Copilot Pro(월 20달러) 필요

삼성전자 갤럭시 북5 Pro, LG 그램 Ultra 등 국내 OEM 파트너 제품에도 동일 업데이트가 적용될 예정이다.

Gartner(글로벌 IT 리서치 기관)는 2026년 기업용 PC 교체 수요의 주요 동인으로 'AI PC'를 꼽았으며, 이번 업데이트는 기업의 교체 주기를 앞당길 수 있는 카드가 됐다.

## 병규의 한 줄

이번 업데이트에서 흥미로운 건 기능보다 위치다. AI가 별도 창이나 앱이 아니라 운영체제 자체에 스며들었다는 것 — 마치 마우스나 키보드처럼, 존재를 의식하지 않고 쓰는 인터페이스가 되겠다는 선언이다. Windows가 AI를 '추가 기능'이 아니라 '기본 인프라'로 재정의하는 순간이다.
