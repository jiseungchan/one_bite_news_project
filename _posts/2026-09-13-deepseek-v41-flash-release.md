## 배경 — 모델 크기와 성능은 정말 비례할까?

AI 업계의 오랜 통념은 "크면 클수록 좋다"였다. 더 많은 파라미터(매개변수 — 모델이 학습으로 얻는 지식의 단위), 더 많은 컴퓨팅, 더 높은 비용이 곧 더 좋은 성능이라는 등식이 당연하게 받아들여졌다. 그래서 기업들은 수천억 개 파라미터짜리 플래그십 모델을 내세우고, 이를 API로 파는 방식으로 수익을 올려왔다.

딥시크(DeepSeek)는 이 공식을 여러 차례 뒤집어왔다. 중국 AI 연구소인 이 회사는 MoE(Mixture of Experts — 전체 파라미터 중 일부만 선택적으로 활성화해 효율을 극대화하는 구조)라는 아키텍처를 앞세워 더 적은 실제 연산량으로 더 높은 성능을 내는 것을 반복해서 보여줬다.

## 핵심 — V4.1 플래시는 무엇이 다른가?

9월 10일 공개된 딥시크 V4.1 플래시는 이 전략의 최신 버전이다. 총 파라미터 수는 5,520억 개(552B)로 이전 V4-플래시(284B)의 거의 두 배에 달한다. 그러나 실제 연산에 사용되는 '활성 파라미터'는 입력 시 80억 개(8B), 출력 시 160억 개(16B)에 불과하다. 나머지는 대기 상태다. 덕분에 추론 속도가 빠르고 비용이 낮다.

주요 특징을 정리하면 이렇다.

| 항목 | V4.1 플래시 | V4-Pro (구형) |
|------|-----------|-------------|
| 총 파라미터 | 552B | 284B |
| 활성 파라미터 | 8B/16B | — |
| 컨텍스트 창 | 100만 토큰 | — |
| 이미지 입력 | 지원 | 미지원 |
| 라이선스 | MIT (오픈소스) | — |

벤치마크(AI 모델 성능을 측정하는 표준 시험) 결과가 흥미롭다. 코딩 에이전트 능력을 측정하는 Terminal-Bench 2.1에서 V4.1 플래시는 90.6점을 기록했다. 앤트로픽 Opus 5(89.1점)와 오픈AI GPT-5.6 솔(88.8점)을 모두 앞선다. 소프트웨어 개발 자동화 능력을 측정하는 DeepSWE v1.1에서는 74.2%로 이전 버전(54.4%)보다 20%포인트 가까이 뛰어올랐다.

가격도 눈에 띈다. 캐시 히트(서버가 이전에 처리한 요청을 재활용하는 것) 기준 입력 토큰 100만 개당 0.003달러다. 출력 토큰 기준으로는 오프피크 시 0.60달러다. 딥시크 측은 9월 14일부터 기존 V4-Pro API 요청을 모두 V4.1 플래시로 자동 전환하겠다고 발표했다. 같은 가격에 더 나은 모델로 바뀌는 셈이다.

## 시장 영향 — 오픈소스 + 고성능의 조합

MIT 라이선스로 허깅페이스(Hugging Face — AI 모델을 공개 배포하는 플랫폼)에 공개된다는 점이 중요하다. 기업이나 개발자가 딥시크의 서버를 거치지 않고 자체 인프라에서 이 모델을 돌릴 수 있다는 의미다.

영향받는 영역을 정리하면:
- **소프트웨어 개발 자동화**: DeepSWE 74.2%는 AI가 실제 GitHub 이슈를 해결할 수 있는 능력이 빠르게 높아지고 있음을 뜻한다
- **클라우드 AI API 시장**: 딥시크가 플래그십급 성능을 저가에 제공하면서 오픈AI·앤트로픽·구글의 가격 압박이 심화된다
- **오픈소스 커뮤니티**: MIT 라이선스 오픈소스이므로 파생 모델과 파인튜닝(특정 용도에 맞게 추가 학습하는 것) 생태계가 빠르게 확산될 전망

## 병규의 한 줄

이번에 흥미로운 건 숫자보다 메시지다. 딥시크는 "플래그십이 뭐가 중요하냐, 실제로 싸고 빠르게 잘 하는 모델이 이긴다"는 걸 반복해서 증명하고 있다. AI 모델 시장에서 '브랜드 프리미엄'이 얼마나 버틸 수 있는지, 그게 지금 업계의 진짜 질문이다.
