## 한 줄 요약
> AI 에이전트의 행동 지침을 '사람이 고쳐 쓰는 것'에서 '기계가 훈련시키는 것'으로 바꾼 연구다.

## 리드 — 왜 지금 이게 중요한가?

Microsoft Research가 2026년 6월 30일 공개한 SkillOpt는 AI 에이전트의 스킬 파일(에이전트에게 어떻게 작업을 수행할지 알려주는 마크다운 지시 문서)을 학습 가능한 매개변수처럼 자동 최적화하는 프레임워크다. GPT-5.5를 기반으로 평균 성능이 58.8에서 82.3으로 23.5포인트 올랐다. 모델 가중치는 건드리지 않은 채, 지시 파일 하나만 다듬어서 낸 결과다.

## 배경 — 기존에는 어땠나?

AI 에이전트에서 "스킬"이란 에이전트가 특정 작업을 수행하는 방법을 서술한 텍스트 파일이다. Codex나 Claude Code 같은 코딩 에이전트가 실제로 어떻게 행동할지를 결정하는 핵심 요소다.

문제는 지금까지 이 파일을 사람이 직접 수정해왔다는 것이다. 수정을 거듭할수록 파일이 길어지고, 한쪽을 고치면 다른 작업 성능이 떨어지는 예측 불가능한 부작용이 생겼다. "아무런 보장 없이 수정하고, 더 나은지도 확인하지 않는 방식"이라는 게 Microsoft Research 팀의 진단이다. 지시 파일 최적화는 여전히 사람의 직관과 시행착오에 의존하는 영역이었다.

## 핵심 — 무엇이 다른가?

SkillOpt는 딥러닝의 '학습' 개념을 텍스트 최적화로 옮겼다. 마치 신경망이 경사하강법으로 가중치를 업데이트하듯, SkillOpt는 스킬 파일을 단계적으로 개선한다.

**동작 방식:**
1. **순전파**: 현재 스킬 파일을 들고 에이전트가 훈련 작업을 수행
2. **역전파**: 별도의 최적화 모델이 실행 경로를 분석하고 추가·삭제·수정 편집을 제안
3. **검증 게이팅(Validation Gating)**: 제안된 스킬이 홀드아웃(검증용 보류 데이터) 세트에서 기존보다 성능이 높을 때만 채택
4. **거부 버퍼(Rejected-edit Buffer)**: 탈락한 수정은 기록으로 남겨 이후 최적화의 부정 피드백으로 활용

최종 산출물은 중간값 기준 약 920토큰 분량의 `best_skill.md` 파일 하나다. 6개 사례 연구에서 각 파일에 실제 반영된 수정은 케이스당 1~4건에 불과했다 — 적게 고쳐 크게 올린 셈이다.

| 항목 | 기존 방식 | SkillOpt |
|---|---|---|
| 스킬 파일 작성 | 사람이 수동 작성·수정 | 자동 최적화 |
| 수정 효과 보장 | 없음 | 검증 게이팅으로 보장 |
| 모델 가중치 변경 | 해당 없음 | 없음 |
| 스킬 파일 길이 | 수정 거듭할수록 증가 | 평균 ~920토큰 유지 |

## 시장 영향 — 어디에 쓰이나?

GPT-5.5 기준 6개 벤치마크 평균:
- **전체 평균**: 58.8 → 82.3 (+23.5점)
- **SpreadsheetBench**(스프레드시트 자동화 벤치마크): 41.8 → 80.7
- **OfficeQA**(오피스 문서 Q&A 벤치마크): 33.1 → 72.1
- **LiveMathematicianBench**(수학 추론 벤치마크): 37.6 → 66.9
- **Codex에서 Claude Code로 스킬 전이**: 22.1 → 81.8 (+59.7점)
- **Qwen3.5-4B**(4B 파라미터 소형 모델): GPT-5.2 no-skill 기준선 상회

특히 소형 모델이 최적화된 스킬 파일 하나로 더 큰 프론티어 모델의 기준선을 넘었다는 점이 눈에 띈다. 비싼 대형 모델 없이도 지시 파일 최적화만으로 격차를 좁힐 수 있다는 의미다. 코딩 에이전트, 오피스 자동화, 수학 추론 등 에이전트가 쓰이는 실무 환경 전반에 적용 가능하다.

## 병규의 한 줄

이번 연구에서 흥미로운 건 성능 수치보다 질문의 전환이다. '어떻게 더 나은 지시를 쓸까'가 아니라 '어떻게 스킬을 훈련시킬까' — AI 에이전트의 행동을 설계가 아니라 학습의 영역으로 옮겼다.
