## 한 줄 요약
> 구글 Gemini 2.5 Pro가 API로 열리면서, AI 모델 전쟁의 전장이 '누가 더 똑똑한가'에서 '누가 더 쓸 수 있는가'로 이동하고 있다.

## 리드 — 왜 지금 이게 중요한가?

구글이 지난 5월 24일 Gemini 2.5 Pro를 개발자용 API로 정식 공개했다. Google AI Studio와 Vertex AI(구글의 기업용 AI 클라우드 플랫폼)를 통해 동시에 접근 가능해졌으며, 소프트웨어 엔지니어링 벤치마크인 SWE-bench(실제 깃허브 이슈를 AI가 스스로 해결하는 능력을 측정하는 시험)에서 72.5%를 기록했다. 이는 OpenAI GPT-5(68.3%)를 앞서는 수치다.

## 배경 — 기존에는 어땠나?

Gemini 2.5 Pro는 지난 3월 Google I/O 2026에서 데모 형태로 처음 공개됐으나, API 접근이 제한적 미리보기(Preview) 상태에만 머물렀다. 개발자들은 대기자 명단에 이름을 올리고 수 주를 기다려야 했고, 기업 고객은 Vertex AI 통한 별도 계약이 필요했다. 반면 OpenAI는 GPT-5 API를 즉시 전면 개방해 개발자 생태계를 빠르게 흡수했다.

구글 입장에서 이 간극은 치명적이었다. 모델 성능이 아무리 뛰어나도 개발자가 쓸 수 없으면 의미가 없기 때문이다. 이번 정식 공개는 그 격차를 메우기 위한 포석이다.

## 핵심 — 무엇이 다른가?

이번 Gemini 2.5 Pro API의 핵심 변화는 세 가지다.

**기존 Gemini 2.0 vs Gemini 2.5 Pro 비교**

| 항목 | Gemini 2.0 Flash | Gemini 2.5 Pro |
|------|-----------------|----------------|
| 컨텍스트 창 | 100만 토큰 | 100만 토큰(유지) |
| SWE-bench | 53.8% | 72.5% |
| 멀티모달 입력 | 텍스트+이미지+오디오 | 텍스트+이미지+오디오+영상 |
| 네이티브 코드 실행 | 제한적 | API 내 샌드박스 실행 |

첫째, **코드 샌드박스 통합**이다. API 호출 내에서 Python 코드를 직접 실행하고 결과를 반환하는 기능이 추가됐다. 마치 AI에게 계산기와 컴파일러를 쥐어준 것과 같다 — 이전에는 "코드를 써줘"까지만 했다면 이제는 "코드를 쓰고, 실행하고, 결과까지 줘"가 가능하다.

둘째, **영상 이해 능력 강화**다. 최대 2시간 분량의 영상을 직접 입력받아 장면을 이해하고 요약하며, 특정 시점의 내용을 질의응답으로 추출할 수 있다.

셋째, **멀티에이전트 오케스트레이션 지원**이다. 여러 Gemini 에이전트가 역할을 나눠 협력하는 구조를 API 레벨에서 직접 지원한다.

## 시장 영향 — 어디에 쓰이나?

- **소프트웨어 개발**: SWE-bench 72.5%는 실제 개발 업무의 상당 부분을 자동화할 수 있다는 신호. GitHub Copilot과의 직접 경쟁이 본격화된다.
- **기업 문서 처리**: 100만 토큰 컨텍스트 창은 약 750페이지 분량의 문서를 한 번에 분석 가능하다. 법률·금융 업계 수요가 크다.
- **미디어·엔터테인먼트**: 2시간 영상 이해 기능은 동영상 콘텐츠 검색과 자막 생성, 광고 타겟팅에 직접 활용된다.
- 구글은 이번 API 출시와 함께 가격도 공개했다. 입력 1백만 토큰당 3.5달러, 출력 1백만 토큰당 10.5달러다. GPT-5 API 대비 약 20% 낮은 수준이다.

## 병규의 한 줄

이번에 흥미로운 건 성능 수치가 아니라 타이밍이다. 구글은 지난 몇 년간 '연구실에서는 세계 최고인데 제품으로는 늦다'는 평가를 받아왔다. Gemini 2.5 Pro를 GPT-5 출시 불과 2주 만에 API로 정식 공개한 것은, 구글이 그 패턴을 의식적으로 깨려 한다는 신호다 — 속도가 전략이 되는 시대가 왔다.
