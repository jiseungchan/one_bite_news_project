## 한 줄 요약
> OpenAI가 소셜 네트워크를 만들려는 건 단순히 사용자를 늘리려는 게 아니라, AI 훈련 데이터의 원천을 자체 확보하려는 구조적 도박이다.

## 리드 — 왜 지금 이게 중요한가?

OpenAI가 ChatGPT 내에 소셜 피드(SNS형 콘텐츠 공유 기능)를 통합하는 방안을 내부적으로 검토 중이라고 MIT Technology Review가 보도했다. 단순한 기능 추가가 아니라, 독자적인 소셜 네트워크 플랫폼 구축까지 범위를 넓히고 있다는 점에서 업계가 주목하고 있다. GPT-5 출시 이후 월간 활성 사용자가 6억 명을 넘어선 시점에 나온 행보다.

## 배경 — 기존에는 어땠나?

AI 모델을 훈련하는 데 필요한 데이터는 주로 인터넷 공개 텍스트(CommonCrawl, 위키피디아, 도서 등)에서 왔다. 그런데 이 방식이 두 가지 벽에 부딪혔다. 첫째, 고품질 공개 데이터가 고갈되고 있다는 연구들이 잇따라 나오고 있다 — 일부 추정에 따르면 인터넷의 유용한 텍스트는 이미 70~80%가 학습에 사용됐다. 둘째, 레딧·X(트위터)·뉴욕타임스 같은 플랫폼들이 API 접근을 유료화하거나 AI 학습 사용을 명시적으로 금지하기 시작했다.

결국 AI 기업들 입장에서 "우리가 직접 데이터를 만들어 내는" 구조가 장기적으로 유리해졌다. 사용자가 AI와 대화하고 그 결과를 공유하는 소셜 피드는, 자연스럽게 인간이 검증한 고품질 인터랙션 데이터를 쌓는 장치가 된다.

## 핵심 — 무엇이 다른가?

OpenAI가 구상 중인 소셜 기능의 핵심은 "AI 생성 콘텐츠 + 사람의 반응"을 한 공간에 쌓는 것이다. 사용자가 ChatGPT와 나눈 대화나 생성된 이미지를 피드에 올리면, 다른 사람들이 반응하고 공유한다. 이 과정에서 생기는 데이터 — 어떤 응답이 좋은 반응을 얻었는지, 어떤 프롬프트가 많이 공유됐는지 — 가 다음 모델 훈련에 직접 활용될 수 있다.

| 항목 | 기존 방식 | OpenAI 소셜 네트워크 방식 |
|------|----------|----------------------|
| 데이터 출처 | 인터넷 스크래핑, 도서, 위키피디아 | 자체 플랫폼 사용자 상호작용 |
| 데이터 품질 검증 | 자동 필터링 (불완전) | 사람의 좋아요·공유로 자연 검증 |
| 저작권 리스크 | 높음 (외부 콘텐츠) | 낮음 (자체 플랫폼 이용약관) |
| 경쟁자 접근 | 동일 공개 데이터 공유 | 독점 데이터 구축 가능 |

비유하자면, 지금까지 AI 기업들은 세상에 이미 있는 책들을 도서관에서 빌려 읽었다. OpenAI는 이제 직접 출판사를 차려 독자들이 책을 쓰고 서로 추천하게 만들겠다는 것이다.

## 시장 영향 — 어디에 쓰이나?

- ChatGPT 월간 활성 사용자 6억 명 이상 — 플랫폼 잠금 효과(lock-in) 강화에 즉각적으로 유리
- 메타의 Threads, X의 Grok 통합 등 소셜+AI 결합 경쟁이 이미 진행 중 — OpenAI 진입 시 3파전 구도
- 광고 수익 모델 가능성: 소셜 피드는 광고 인벤토리로 전환 가능 — OpenAI의 수익 다각화 시나리오에 부합
- 크리에이터·마케터 직군이 가장 먼저 영향을 받을 전망 — AI 생성 콘텐츠 배포 채널이 하나 더 생기는 구조

## 병규의 한 줄

이번에 흥미로운 건 소셜 네트워크 자체가 아니라 그 속에 담긴 논리다. '데이터를 구하는 회사'에서 '데이터를 생산하는 플랫폼'으로의 전환 — OpenAI가 AI 기업에서 인프라 기업으로 변모하려는 야심을 보여주는 행보다.
