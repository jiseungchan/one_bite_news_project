## 한 줄 요약
> 클로바X 3.0은 한국어 AI 모델의 경쟁 축이 '성능'에서 '에이전트 통합'으로 이동했음을 보여준다.

## 리드 — 왜 지금 이게 중요한가?
네이버가 9월 29일 클로바X 3.0을 공개했다. 이전 버전이 '한국어를 잘하는 대형 언어 모델(LLM)'에 초점을 맞췄다면, 3.0은 '네이버 서비스를 직접 다루는 에이전트'로 방향을 전환했다. 가장 주목할 변화는 '네이버 에이전트 툴킷' 연동이다. 클로바X 3.0은 네이버 검색·쇼핑·예약·클라우드 API(응용프로그램 인터페이스 — 서로 다른 소프트웨어가 대화하는 통로)를 직접 호출해 사용자의 지시를 실제 행동으로 완료할 수 있다.

## 배경 — 기존에는 어땠나?
클로바X 1.0, 2.0은 한국어 이해·생성 성능을 글로벌 모델과 경쟁하는 데 집중했다. 2026년 4월 출시된 2.0은 한국어 벤치마크에서 GPT-4o를 앞서며 주목받았다. 그러나 한계도 분명했다. 텍스트 생성과 요약에는 강했지만, 실제 서비스에서 '무언가를 대신 해주는' 에이전트 기능은 GPT-6 아스트라나 구글 제미나이 에이전트에 비해 뒤처진다는 평가를 받았다. 네이버 내부에서도 '한국어를 잘하는 것'만으로는 생태계 잠금 효과를 만들기 어렵다는 인식이 커졌다.

## 핵심 — 무엇이 다른가?
클로바X 3.0의 핵심 변화는 두 가지다. 첫째, 네이버 서비스 직접 조작이다. 사용자가 "이번 주 금요일 저녁 강남에서 4인 식당 예약해줘"라고 말하면, 클로바X 3.0이 네이버 플레이스 예약 API를 직접 호출해 예약을 완료한다. 기존에는 검색 결과를 안내하는 수준에 그쳤다. 둘째, 한국어 다중 에이전트 협업이다. 여러 클로바X 인스턴스가 동시에 작업을 분담하는 멀티에이전트(Multi-agent — 여러 AI가 역할을 나눠 협업하는 구조) 기능이 기업 고객(B2B)용으로 제공된다.

| 항목 | 클로바X 2.0 | 클로바X 3.0 |
|------|-----------|-----------|
| 주요 능력 | 한국어 생성·요약 | 서비스 직접 조작 |
| 에이전트 기능 | 제한적 | 네이버 생태계 전체 |
| B2B 기능 | 없음 | 멀티에이전트 지원 |
| API 연동 범위 | 외부 플러그인 중심 | 네이버 자체 API 우선 |

## 시장 영향 — 어디에 쓰이나?
네이버는 3.0을 네이버 클라우드 플랫폼(NCP)을 통해 기업 고객에게 우선 제공한다. 금융·커머스·공공 분야가 1차 타깃이다. 이커머스 고객 서비스 자동화, 금융 문서 처리, 공공기관 민원 처리 자동화 등이 초기 활용 시나리오로 제시됐다.

## 병규의 한 줄
네이버가 3.0에서 선택한 방향은 '한국어 잘하는 모델'보다 '한국 서비스와 엮인 에이전트'다. 글로벌 모델과 성능 경쟁을 벌이는 대신, 자신만이 가진 생태계를 잠금장치로 활용하는 전략이다 — 경쟁에서 이기는 방법이 아니라, 경쟁 자체를 다른 게임으로 바꾸는 방법이다.
