## 한 줄 요약
> 거대 모델 없이도 작동하는 AI 에이전트가 가능하다 — 마이크로소프트가 소형 모델 전용 설계로 이를 실증했다.

## 리드 — 왜 지금 이게 중요한가?

AI 에이전트 경쟁이 대형 모델 중심으로 흘러가던 흐름에서 마이크로소프트 리서치가 역방향 실험 결과를 내놨다. 5월 21일 공개한 MagenticLite 시스템은 14B·9B·27B급 소형 모델 조합만으로 브라우저 탐색, 파일 조작, 코드 실행 같은 복잡한 에이전트 작업을 처리한다. GPT-4o나 Claude 같은 수백B 파라미터(모델의 학습 가능한 변수 수 — 클수록 일반적으로 성능이 높지만 비용도 높다)급 모델 없이 이 수준을 구현한 건 처음이다.

## 배경 — 기존에는 어땠나?

AI 에이전트(사용자의 목표를 받아 여러 단계에 걸쳐 스스로 판단하고 행동하는 AI 시스템)는 지금까지 대형 모델에 의존해왔다. 이유는 간단하다. 에이전트 작업은 단순 질문 답변과 달리 "지금 어느 페이지를 보고 있고, 다음에 무엇을 클릭해야 하고, 실패하면 어떻게 복구할지"를 한꺼번에 판단해야 한다. 이 추론 부담을 소형 모델이 감당하기 어렵다는 게 업계의 통설이었다.

실제로 기존 연구에서 소형 모델 기반 에이전트는 웹 탐색 벤치마크에서 대형 모델 대비 성능이 크게 뒤처지는 결과가 반복됐다. 비용을 줄이려면 성능을 포기해야 한다는 트레이드오프가 당연하게 받아들여졌다.

## 핵심 — 무엇이 다른가?

마이크로소프트 리서치가 내놓은 답은 "모델 크기 대신 역할 분리"다. MagenticLite는 세 구성 요소로 나뉜다.

**MagenticBrain** — 14B 파라미터 오케스트레이터(전체 작업을 지휘하는 모델). Qwen 3 14B를 기반으로 파인튜닝(사전학습된 모델을 특정 목적에 맞게 추가 학습하는 기법)했다. 계획 수립, Python 코드 작성, 터미널 명령 실행, 하위 에이전트 위임을 담당한다.

**Fara1.5** — 브라우저 조작 전담 컴퓨터 사용(Computer-Use) 모델. 4B·9B·27B 세 가지 크기로 제공되며, 추천 모델인 9B가 이전 세대 Fara-7B 대비 웹 내비게이션 성능을 거의 2배 끌어올렸다. 27B 모델은 Online-Mind2Web 벤치마크(AI가 웹사이트를 실제로 탐색하는 능력을 측정하는 평가 지표)에서 90% 이상 성능을 달성해 현재 공개 모델 중 최고 수준을 기록했다. Alibaba의 Qwen 3.5 아키텍처 기반이다.

**Quicksand 샌드박스** — QEMU(가상화 소프트웨어) 기반 격리 환경에서 실행돼 에이전트가 로컬 시스템에 미치는 영향을 통제한다.

| 항목 | 기존 방식 | MagenticLite |
|------|-----------|----------|
| 핵심 모델 크기 | 수백B 파라미터급 | 14B + 9B |
| 역할 구조 | 단일 모델이 모든 판단 | 오케스트레이터·전문가 분리 |
| 브라우저 처리 | 모델 내부 추론 | Fara1.5 전담 위임 |
| 보안 격리 | 호스트 OS 직접 접근 | Quicksand 샌드박스 |

사람에 비유하면, 혼자 모든 걸 처리하는 슈퍼맨 한 명 대신 지휘관(MagenticBrain)과 전문 필드 요원(Fara1.5)이 역할을 나누는 구조다.

## 시장 영향 — 어디에 쓰이나?

- Fara1.5-27B: Online-Mind2Web 벤치마크 90% 이상 달성 — 공개 소형 모델 중 현재 최고 성능
- Fara1.5-9B: 전 세대 대비 웹 탐색 성능 약 2배 향상
- MagenticBrain: Microsoft Foundry에서 공개 제공
- Fara1.5 전 모델군: Microsoft Foundry에서 접근 가능
- MagenticLite 애플리케이션: GitHub 공개

온프레미스(자체 서버) 또는 비용 민감 환경에서 에이전트를 운영해야 하는 기업, 대형 API 비용 없이 자동화 에이전트를 구축하려는 개발자들에게 직접적인 대안이 된다.

## 병규의 한 줄

이번 연구에서 흥미로운 건 모델 크기가 아니라 설계 원칙이다. "에이전트 능력은 지식이 아닌 도구 오케스트레이션과 실행에서 나온다"는 가정 — 이걸 소형 모델로 증명했다는 점이 진짜 메시지다.
