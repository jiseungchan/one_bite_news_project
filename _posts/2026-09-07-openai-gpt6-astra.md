## 이번에 흥미로운 건 수치보다 철학이다

오픈AI가 9월 3일 GPT-6 아스트라(Astra)를 공개하면서 한 가지 메시지를 반복했다. "가장 지능적이고 정렬된 모델"이라는 수식어보다, '장시간 자율 작업'에 맞게 설계했다는 점이다. 벤치마크 점수를 끌어올리는 데 집중하기보다 — 실제로 독립 테스트에서 전반적 지능 점수는 전작과 비슷하게 나왔다 — 컴퓨터를 직접 조작하고, 브라우저를 탐색하고, 터미널에서 코드를 돌리는 '에이전트 태스크(자율적으로 여러 단계 작업을 처리하는 AI 기능)'에 개발 역량을 집중했다.

## 기존에는 어땠나

GPT-5.6 Sol까지, 고성능 AI 모델들은 대화 속에서 문제를 풀거나 코드를 생성하는 데는 강했지만 '중간에 멈추는' 문제가 있었다. 복잡한 멀티스텝 작업 — 예를 들어 "웹사이트를 열고 로그인해서 데이터를 추출한 뒤 정리해 파일로 저장해줘" 같은 흐름 — 을 자율로 완수하지 못하고 중간에 사람이 개입해야 했다. 에이전트 AI의 '마지막 10%'는 여전히 인간 몫이었다.

## 아스트라가 다른 점

핵심 변화는 세 가지 지표에서 드러난다.

**OS 조작 능력** — OSWorld 2.0(AI가 실제 운영체제를 조작해 과제를 수행하는 벤치마크)에서 GPT-5.6 Sol이 65.7%를 75분 만에 처리한 것을 아스트라는 72.6%를 40분 만에 끝냈다. 성공률이 높아졌고 시간은 절반 가까이 줄었다.

**UI 클릭 정확도** — ScreenSpot Pro(화면에서 정확한 UI 요소를 찾아 클릭하는 벤치마크)에서 76.9%에서 92.7%로 뛰었다. 열 개의 버튼 중 잘못 누르는 경우가 크게 줄었다는 뜻이다.

**자동화 체인** — AutomationBench(여러 단계 자동화 작업을 얼마나 완수하는지 측정)는 18.1%에서 41.4%로 두 배 이상 올랐다. '한 번에 처리'의 범위가 넓어졌다.

그리고 사이버보안. 오픈AI는 아스트라가 자사 모델 중 처음으로 '크리티컬 사이버보안 기준(Critical Cybersecurity Capability Threshold)'에 도달했다고 밝혔다. 이는 적절한 도구와 접근 권한이 주어지면 이전에 알려지지 않은 취약점을 찾고 익스플로잇 체인(취약점을 연결해 공격 경로를 만드는 방식)을 구성할 수 있다는 의미다. 오염 통제 환경에서 측정한 ExploitBench에서 GPT-5.6 Sol의 5.5%를 아스트라는 39.0%로 압도했다.

| 항목 | GPT-5.6 Sol | GPT-6 Astra |
|------|-------------|-------------|
| OSWorld 2.0 성공률 | 65.7% (75분) | 72.6% (40분) |
| ScreenSpot Pro | 76.9% | 92.7% |
| AutomationBench | 18.1% | 41.4% |
| ExploitBench | 5.5% | 39.0% |

## 스펙과 가격

컨텍스트 창(한 번에 처리할 수 있는 텍스트 양)은 105만 토큰으로 업계 최대 수준이며, 최대 출력은 12만 8,000 토큰이다. 지식 컷오프는 2026년 4월 30일. 입력 텍스트와 이미지를 동시에 받는다.

가격은 API 기준 입력 100만 토큰당 $10, 출력 100만 토큰당 $50. 캐시(이미 처리한 내용을 재활용하는 기능) 입력 시 $1, 캐시 쓰기 $12.50. 전작 GPT-5.6 Sol 대비 2.5배 비싸다.

출시는 단계적으로 진행된다. Daybreak 프로그램 소속 기업 고객 먼저, 이후 ChatGPT Plus·Pro·Business·Enterprise 순, 그다음 OpenAI API와 AWS로 확대된다.

## 병규의 한 줄

이번 아스트라가 보여주는 건 '더 똑똑한 AI'가 아니라 '더 오래 혼자 일하는 AI'라는 방향 전환이다. 오픈AI는 범용 지능 경쟁에서 한 발짝 물러나 에이전트 실용성에 집중하는 카드를 꺼냈다. 이게 맞는 선택인지는 반년 후 기업 도입 사례들이 말해줄 것이다.
